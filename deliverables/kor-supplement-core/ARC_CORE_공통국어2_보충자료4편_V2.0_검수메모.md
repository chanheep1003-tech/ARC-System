## 3. 원문 확보와 무결성

**출처.** Drive `sources/` 폴더(ID `1j7SD3pFH49_DKOKLf536l2LnJXGspOXc`)의 `보충_01_탄궁가.md`, `보충_02_팔원.md`, `보충_03_기억할만한지나침.md`, `보충_04_칸트헤겔자유.md`. 「이존당기」는 범위 밖이라 쓰지 않았다.

| 자료 | 로컬 파일 | 바이트 | SHA-256(앞 16자리) |
|---|---|---:|---|
| 탄궁가 | `src/raw_01_tangungga.md` | 2,700 | `eb55337abc56af2e` |
| 팔원 | `src/raw_02_palwon.md` | 1,227 | `7ff95ad4589eca3b` |
| 기억할 만한 지나침 | `src/raw_03_memory.md` | 990 | `95c120ee2bbf0104` |
| 칸트·헤겔 | `src/raw_04_kant_hegel.md` | 4,556 | `467e5ff44dfba142` |

전체 해시는 `src/SOURCES.sha256`에 있다.

**확보 방법과 발생한 오류.** Drive 읽기 도구는 파일을 base64로 준다. 손으로 옮기는 과정에서 「탄궁가」에 글자 두 곳의 잘못된 치환("주단"→"주니", "하는"→"하늘")이, 「칸트·헤겔」에 여러 문단의 훼손이 생겼다. 파일 크기가 Drive 값과 달라서(칸트·헤겔 4568 대 4556) 발견했고, 독립적으로 다시 옮긴 사본과 대조해 고쳤다. 지금의 바이트 수는 Drive가 알려 준 크기(2700/1227/990/4556)와 같다.

**한계.** 이 환경의 Drive 도구는 체크섬을 주지 않아서, 로컬 SHA-256을 Drive 쪽 해시와 직접 대조하지는 못했다. 무결성은 바이트 수 일치와 독립 사본 대조로 확인한 것이다.

**PDF 안의 원문 검사.** 최종 PDF에서 글자를 다시 추출해 원본과 견주었다.

| 작품 | 결과 |
|---|---|
| 탄궁가 | 42행 중 42행 일치 |
| 팔원 | 16행 중 16행 일치, 주석 5개 포함 |
| 기억할 만한 지나침 | 14행 중 14행 일치(연 구분 1곳), 주석 포함 |

해설 안의 인용 169곳은 빌드할 때마다 원본과 자동으로 대조한다. 하나라도 원본에 없으면 빌드가 멈추게 했고, 인용 뒤의 위치(행·문단)도 원본에서 계산해 붙였다. 학생용 원문 블록은 `src/`의 원본에서만 생성했다.

**원문 관련 확인 필요 사항.**
- 세 편의 시 원문(예: 「팔원」 10행 "내지(內地) 주재소장 같은 어른과 어린아이 둘이 내임을 낸다")을 표준 판본과 대조하지 않았다. 자료 원문을 그대로 실었다(미확인).

## 6. 외부 자료 사용

- **검색.** WebSearch 15회(작품 해설, 갈래 특성, 고사, 작가·창작 정보, 이행남 논문 서지 등).
- **열람 시도.** WebFetch 5건이 모두 실패했다. `encykorea.aks.ac.kr`, `www.kci.go.kr`, `ko.wikipedia.org`, `namwon.grandculture.net`은 네트워크 프록시가 차단했고(EGRESS_BLOCKED), `blog.daum.net`은 주소를 찾지 못했다. 우회하지 않았다.
- **결과.** 외부 자료는 검색 결과의 제목과 발췌만 확인했다. 원문 페이지를 직접 읽은 자료는 없다. 그래서 †로 표시한 항목은 "여러 검색 발췌가 같은 방향이거나 일반적으로 알려진 사실"에 해당하고, 문장 단위로 검증한 것은 아니다.
- 「탄궁가」가 2014·2015 EBS 인터넷 수능 문학과 2015년 9월 모의고사 목록에 제목으로 올라온 것이 검색 결과에서 보였다. 문항·정답은 열어 보지 않았고 출제 경향의 근거로 쓰지 않았다. 본문에 "빈출", "반드시 출제" 표현은 없다(원고 전체 검색으로 확인).
- 개념서·해설의 문장이나 구조를 옮기지 않고 사실과 개념만 참고해 새로 썼다.
- 이행남 논문은 제목이 같은 논문이 검색 결과에 나오는 것을 확인했다. 게재지와 연도(『철학연구』 116집, 2017)는 검색 발췌 기준이며 원문은 읽지 못했다. 본문 해설은 보충자료 원문만 근거로 썼다.

## 9. 용어·표기·해석 충돌

- **헤겔 표기.** 국어 마스터의 표기는 "윤리적"인데, 보충자료 제목과 본문은 "인륜적"이고, 본문의 정의는 "구체적 자유"이다. 본문은 자료 표기를 따르고, 제목의 '인륜적 자율성'과 본문의 '구체적 자유'를 같은 것으로 단정하지 않았다(본문 정의 기준).
- **「탄궁가」 구분.** 서사·본사·결사 구분은 보충자료가 아니라 학습 자료에서 온 것이다(†◇).
- **「팔원」 12행.** "어느 한 사람도 눈을 씻는다"의 주체를 확정하지 않았다.
- **「기억할 만한 지나침」.** 울음의 이유, 화자와 서기의 관계를 확정하지 않았다.
- **시험 출제 여부.** 어떤 개념도 실제 출제로 확인한 것이 없다. 개념 장 첫머리에 그렇게 밝혔다.
- **선지 판단 연습.** 모두 이 노트에서 새로 쓴 학습용 예시이며 실제 기출이 아니다. 본문에 그 사실을 적었다. 칸트·헤겔의 "(학습용 사례)" 두 건도 새로 만든 예이다.

### 도구

HTML→PDF는 Chromium(Playwright)으로, 병합·쪽 번호·러닝 헤드·검사는 PyMuPDF로 했다. 외부 PDF 프리플라이트 도구는 쓸 수 없어 별도 프리플라이트는 하지 않았다(TOOLING_UNAVAILABLE). Pretendard는 정적 TTF를, Noto Sans KR은 woff2를 npm 패키지에서 받아 썼다. Noto Sans KR 파일은 내부 이름표가 "Thin"으로 되어 있어서 Regular·SemiBold·Bold로 고쳐 넣었다.
