# 시험 직전 정리
%kicker 마무리
%sub 판단의 순서와 오답 유형

작품마다 정리한 항목을 다시 나열하지 않고, 어느 작품에서든 선지를 판단할 때 반복해서 쓰는 순서와 자주 틀리는 유형을 한곳에 모았다.

## 선지를 판단하는 순서

1. **무엇을 묻는지 정한다.** 내용 일치, 표현과 효과, 화자의 태도, 시상·구조, 작품 비교 가운데 어느 것인지 먼저 가른다.
2. **근거가 되는 행이나 문단을 찾는다.** 선지의 낱말이 아니라 원문의 위치를 먼저 확인한다.
3. **근거가 서술인지 해석인지 가린다.** 원문에 나온 말인지, 읽는 사람이 붙인 해석인지 구분한다. 「팔원」의 관찰과 짐작, 「탄궁가」 15행처럼 풀이가 갈리는 구절이 여기에 해당한다.
4. **표현법의 이름과 효과를 따로 확인한다.** 이름이 맞아도 효과가 틀린 진술이 많다.
5. **일반화의 범위를 본다.** 부분의 정서나 한 문단의 진술을 작품 전체로 넓히지 않았는지 확인한다.

## 자주 틀리는 판단 유형

| 유형 | 판단 방법 | 이 노트의 사례 |
|---|---|---|
| 표현법은 맞고 효과는 틀림 | 이름과 효과를 각각 확인한다 | 「탄궁가」 5~6행 전고는 견줌이지 다짐이 아니다 |
| 일부만 참인 진술 | 앞부분이 맞아도 전체 명제를 끝까지 확인한다 | 「탄궁가」 결사에서 태도가 바뀐다(참)는 맞지만 ‘가난을 즐긴다’(거짓)는 틀리다 |
| 관찰과 추론의 혼동 | 어미와 표지로 구분한다 | 「팔원」 10행 ‘같은’, 13~16행 ‘~을 것이다’ |
| 원문에 없는 내용의 확정 | 원문에 나온 것까지만 인정한다 | 「기억할 만한 지나침」 울음의 이유, 「팔원」 12행 ‘어느 한 사람’의 정체 |
| 부분을 전체로 일반화 | 위치와 범위를 확인한다 | 「탄궁가」 작품 전체가 절망(또는 만족)이라는 서술 |
| 공통점은 맞으나 이유가 다름 | 공통점과 근거를 따로 본다 | 칸트·헤겔 모두 ‘선택의 자유’를 자유로 보지 않지만 이유가 다르다 |
| 방향·순서·소속의 바꿔치기 | 단계와 특징을 짝지어 확인한다 | 「기억할 만한 지나침」의 과거와 현재 연, 헤겔의 세 단계 특징 |

## 작품별 한 줄 핵심

| 작품 | 한 줄 핵심 | 가장 자주 틀릴 판단 |
|---|---|---|
| 「탄궁가」 | 원망하던 화자가 귀신의 항변을 듣고 가난을 분수로 받아들인다 | 결말을 ‘즐김’으로 읽는 것 |
| 「팔원」 | 본 것과 들은 것을 바탕으로 아이의 지난 삶을 짐작한다 | 짐작을 사실로 읽는 것 |
| 「기억할 만한 지나침」 | 우연히 지나친 장면을 지금 떠올리며 서기를 존중한다 | 연의 시간 순서와 울음의 이유 |
| 칸트·헤겔 | 칸트는 이성이 원인일 때, 헤겔은 관계와 제도 속에서 자유가 실현된다 | 원인 대신 겉모습으로 판단하거나 단계의 특징을 바꾸는 것 |
