## 3. 방법과 한계 (중요)
1. 목록·다운로드 URL은 EBSi 공개 목록 API(`previousPaperListAjax.ajax`)와 공개 파일 서버(`wdown.ebsi.co.kr`)에서 얻었다. 로그인 없이 받을 수 있었다.
2. 문항 색인은 해설 PDF의 `N. [출제의도] …` 줄과 정답표를 파싱한 것이다. 출제의도 문구는 공식 해설의 원문이며, `scope_id`/`scope_relation`은 **정규식 키워드 매칭**(SCOPE 정의는 `SCOPE_MAP.csv`와 개념명 기준)으로 만든 잠정 분류다. 매칭은 `[출제의도]` 제목 줄에만 적용했고(해설 본문은 2단 조판에서 다른 문항 글이 섞여 제외), 같은 문항이 잠정 남은 범위와 중간 대조 범위 키워드에 함께 걸리면 `NEEDS_SCOPE_CHECK`로 두었다. 키워드가 넓어 오탐(예: 물리 과목의 '에너지')이 남아 있을 수 있어 육안 검토가 필요하다.
3. 해설 형식이 `[출제의도]`가 아닌 오래된 시험(대체로 2013년 이전)과 정답이 표가 아닌 형식은 문항 색인에서 빠졌다. 해당 시험은 SOURCES에는 있고 ITEMS에는 없다.
4. `pdf_page`는 문제 PDF 각 쪽에서 `N.` 줄머리를 찾은 값이라 2단 조판에서 틀릴 수 있다. `printed_page`는 확인하지 않아 비워 뒀다. 도표·그림이 필요한 문항은 `visual_required`로 표시했고 **육안 확인 전**이다.
5. `common_trap`(오답 함정)은 문항 본문을 읽기 전이라 비워 뒀다. 교사 의도·출제 확률은 추정하지 않았다.
6. 고2·고3 문항은 모두 `PARTIAL_REFERENCE`이며 `extra_prerequisite`에 "상위학년 지식 필요 여부 미확인"을 적었다. 고1 남은 범위와의 대응은 문항별 육안 검토가 필요하다.
7. `source_curriculum`: 2025~2026 고1 통합 시험만 `2022_REVISED`, 2018~2024 고1 통합 시험은 `2015_REVISED`, 나머지는 `UNKNOWN`으로 두었다(연도 기반 판단, 문서로 확인한 것은 아님).
8. SHA-256은 확보한 문제 PDF에 대해서만 계산했다. 정답 PNG는 EBSi가 이미지로만 제공하며 대부분 접근 가능하지 않았다(해설 PDF의 정답표로 대체).
