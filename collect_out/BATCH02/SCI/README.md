## 2. SCOPE_MAP (code 기준 v2)
- 기준: 공식 성취기준 코드(10통과2-01~03). 성취기준 코드: 경기도교육청 「과학탐구(통합과학) 영역 문항 자료집」·KICE 「예시문항 안내」 공식 쪽에서 직접 확인.
- 중간/기말 구분은 사용자가 말한 "2학기 중간 범위 제외"에 대해 ARC 과거 중간 기록(교과서 쪽수는 당시 출판사 기준)을 코드에 대응시킨 **잠정값**이다. 학교 공지가 나오면 바꿔야 한다.
- 경계가 불명확한 코드는 `NEEDS_SCOPE_CHECK`로 두었다: 10통과2-02-04.
- BATCH01의 키워드 기반 scope_id는 `SCOPE_CROSSWALK_BATCH01.csv`로 코드와 연결했다. BATCH01 ITEMS 행은 수정하지 않았다(일부 BATCH01 분류는 이 코드 기준과 다를 수 있음).

## 3. 방법과 검증
- KICE 예시 문항지 25문항: 6쪽 텍스트를 읽고 문항별 성취기준·요지를 직접 작성했고 정답은 공식 정답표 값. 그림·그래프는 텍스트 추출로만 확인.
- 경기도교육청 자료집·KICE 안내서: 공식 "문항 정보" 칸에서 성취기준 코드·내용 요소·행동 영역·정답을 **텍스트로 자동 추출**했다. 정답 칸이 추출되지 않은 문항은 `UNVERIFIED`. 각 자료집에서 1문항씩(경기 통합사회 2번, 통합과학 14번)은 이미지로 확인해 정답이 일치했다.
- PDF 한 쪽이 인쇄 2쪽 펼침면인 자료집은 `printed_page`를 "왼쪽-오른쪽"으로 적었다.
- 한 문항이 여러 성취기준에 걸리면: 남은 범위만이면 DIRECT_REMAINDER, 중간 범위만이면 MIDTERM_ONLY, 둘 섞이면 PARTIAL_REFERENCE, 통합과학1/통합사회1 코드가 섞이면 PARTIAL_REFERENCE와 extra_prerequisite, 경계 코드가 있으면 NEEDS_SCOPE_CHECK.
- KICE 예시문항 안내서 원본 서버 파일은 받지 못해 대학교육협의회 게시본을 썼고, 메가스터디 게시본과 줄 단위 텍스트가 일치했다.
- `common_trap`(오답 함정)은 해설을 읽기 전이라 비워 뒀다. 교사 의도·출제 확률은 추정하지 않았다.
