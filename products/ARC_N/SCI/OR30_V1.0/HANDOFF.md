## SECTION C — 핵심 풀이 메모 (교사용)

- 07: (가)→(나) 반응한 X<sup>+</sup> 4 → Y 2개이므로 Y<sup>2+</sup>. (다) Z 3개가 전자 2+4=6개를 잃으므로 Z<sup>2+</sup>, Y가 잃은 4개의 1.5배.
- 11: B <i>b</i>개 → 양이온 변화 <i>b</i> − 3<i>b</i> = −10N, <i>b</i> = 5N, 남은 A<sup>+</sup> 9N, B가 잃은 전자 15N.
- 15: 4<i>a</i> + 2<i>b</i> = 8 (전하 ≤ 3) → <i>a</i> = 1, <i>b</i> = 2. C 2개가 A<sup>+</sup> 4개를 환원 → C<sup>2+</sup>, B<sup>2+</sup>는 그대로 → B > C > A.
- 19: Ⅱ에서 6 − <i>c</i> + 3 = 7 → <i>c</i> = 2, Ⅰ에서 8 − 6/<i>a</i> + 3 = 5 → <i>a</i> = 1.
- 25: <i>a</i> + <i>b</i> = 8, <i>a</i> + 2<i>b</i> = 13 → A 3N, B 5N, 반응한 C<sup>+</sup> 6N + 15N = 21N.
- 27: 0~3N 구간 C 3N이 B<sup>3+</sup> 2N(전자 6N)을 환원 → C<sup>2+</sup>. C 4N일 때 A<sup>+</sup> 2N 환원되어 2N 남음.
- 30: Y<sup>+</sup> 4N 석출(+432), Z 2N 녹음(−130) → +302. 이후 X 2N 석출(+128), Z 2N 녹음(−130) → 300. 양이온 수는 일정해도 반응은 진행.
