## SECTION C — 방향 판단 규칙 (교사용)

- 그림 코일(진한 선 “/”가 앞쪽): 왼쪽 도선으로 전류가 들어가면 코일 내부 자기장은 왼쪽 → 왼쪽 끝이 N극.
- 저항이 코일 아래에 걸린 경우: 코일 왼쪽 도선으로 들어가는 전류는 저항에서 오른쪽 → 왼쪽으로 흐른다.
- 수평 고리: 위에서 볼 때 시계 반대 방향 = 유도 자기장 위쪽 = 앞쪽(아래 반원) 화살표 오른쪽.
- 02: S극 후퇴 → 내부 유도 자기장 오른쪽 → 오른쪽 끝 N극, 저항 a → b, 서로 당김.
- 15: (+)극이 A의 왼쪽 도선 → A 내부 자기장 왼쪽(왼쪽 끝 N). 닫는 순간 B 내부 유도 자기장 오른쪽 → 저항 c → d, 서로 밂.
- 20: (+)극이 A의 오른쪽 도선 → A 오른쪽 끝 N. 접근 시 B 내부 유도 자기장 왼쪽 → 저항 d → c. 전지를 떼면 반대(c → d).
