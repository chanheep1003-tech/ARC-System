Date:2026-11-07; amended 2026-11-08 by user decisions (ops/ARC_DECISIONS_20261108.md). User correction supersedes the previously inferred ZIP/Academic-B presentation for ARC_N.
Visual ground truth: uploaded 통합과학2_중화집중_100Q_V2.0.pdf pp1,3–4; uploaded 공통국어2_한글맞춤법_100Q_V1.0.pdf p3. Both were rendered and compared directly. Do not infer identity from prose/CSS tokens alone.
- ARC_N science adopts the actual science PDF: pure black/white cover with top institutional line, outlined edition badge, two-line bold title, boxed scope and coverage table. No navy/burgundy Academic B cover. Korean reference has subject-specific serif passages; do not impose science's diagram policy on it.
- Cover logo (2026-11-08): the cover carries the approved B/W logo asset ARC_N_LOCKUP_MASTER_BW.png under the brand asset gate (exact Drive ID + SHA-256, no redraw, no runtime recolor of the color master). While that asset is not registered in templates/brand/ARC_BRAND_ASSET_REGISTRY_V1.0.md the cover is blocked with BRAND_ASSET_MISSING.
- A4, horizontal margin12.8mm; two columns separated by7.8mm and0.6pt line. Base layout is four questions per page: two per column, reading left1/2 then right3/4, the first question of each column starting at56pt from the page top (the reference PDF places the second at416pt when two ordinary-size questions fill a column). User decision 2026-11-08: four is the baseline, not a cap. When a whole further question still fits in the space left after the baseline questions, place it on the same page (5, 6 or more per page). Questions are never split, shrunk below the size tokens, or have conditions removed to make them fit.
- Passage sets (2026-11-08): a set that shares a passage is placed as one flow. The passage is placed once and continues across columns/pages as needed, its linked questions follow it as a KEEP_TOGETHER group, then the ordinary packing above resumes for passage-free questions. This is not a FULL_WIDTH or one-column fallback; ARC_N stays COLUMN_ONLY.
- Running head8.8pt bold with thin bottom rule; left full series/subject/title/version, right current question range. Footer8pt, thin line and centered physical page number.
- Full-column metadata strip,0.7pt black border,7.3pt bold. Include only actual provided source/description and the estimated difficulty shown as the internal grade D1–D5 exactly (2026-11-08 user decision); never fabricate points or exam origin. The difficulty appears only in this strip, never in stems, choices or the answer page, and ARC_FINAL shows none.
- Stem9.1pt bold700, leading12.9pt, hanging number indent. Choices8.4pt, leading11.6pt. Short choices use a three-column grid (①②③ / ④⑤), long choices stack with hanging indent. This is a critical difference from the superseded all-vertical choice style.
- Material boxes and data tables use white fill/black thin borders. Science material uses sans serif; Korean passages follow observed serif reference. Vector diagrams retain all source labels and chemistry glyphs.
- Keep each full question whole inside one column. If it does not fit in the remaining space, move the whole question to the next column/page instead of shrinking below tokens, cropping, or deleting conditions.
- Sequence: cover/blank verso/problem pages/blank separator (exactly one)/quick answer table (starts LAST_PROBLEM_PAGE+2, full-width grid on this non-problem page); separate solution booklet.
- Visual match gate: compare actual rendered cover, full-width metadata strip, question packing (four baseline, more when whole questions fit), horizontal choices, rule widths and footer against the uploaded PDF. Text/data/options/key fidelity remains required.
- ARC_FINAL and ARC_CORE retain their separate active layouts; this correction is ARC_N-specific.
