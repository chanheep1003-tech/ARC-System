UNIT 02

수용액 속 금속과 양이온의 양적 관계 및 전하량 보존

01반응 몰수비는 두 금속 이온의 ‘전하량 역수비’와 일치한다

금속 A(산화수 +a)를 금속 Bᵇ⁺ 이온 수용액에 넣으면, A가 산화되면서 내놓은 총 전자 수와 Bᵇ⁺가 환원되면서 얻은 총 전자 수가 항상 같아야 한다. 따라서 수용액 전체의 양이온 총 전하량 합은 반응이 진행되는 내내 일정하게 보존된다.

핵심 공식  |  b A(s) + a Bᵇ⁺(aq) → b Aᵃ⁺(aq) + a B(s)  ⇒  Δn(Bᵇ⁺) : Δn(Aᵃ⁺) = a : b
• 완결점(변곡점) 전하량 비 공식 : (초기 Bᵇ⁺ 총수 N₀) : (완결 후 Aᵃ⁺ 총수 N_f) = a : b
02이온 전하량 대소에 따른 수용액 물성 변화 비교
전하량 조건 이온 수 증감 메커니즘 총 양이온 수 그래프 수용액 질량 · 밀도 변화
a > b (예: Zn²⁺ / Ag⁺) Ag⁺ 2개 감소 시 Zn²⁺ 1개 생성 완결점까지 일정하게 감소 (↓) 원자량 비교: Zn < 2Ag → 질량 ↓
a = b (예: Zn²⁺ / Cu²⁺) Cu²⁺ 1개 감소 시 Zn²⁺ 1개 생성 처음부터 끝까지 일정 (─) 원자량 비교: Zn > Cu → 질량 ↑
금속 + 산 수용액 (Zn²⁺ / H⁺) 2H⁺ 감소 시 Zn²⁺ 1개 생성, H₂ 발생 완결점까지 일정하게 감소 (↓) Zn > H₂ → 수용액 질량 항상 ↑
03변별 포인트 및 쟁점 선지 즉각 판정 기준
변별 포인트 1 | 혼합 수용액(A⁺, B²⁺)에 금속 C를 넣을 때 석출 순서의 역설

금속 C가 전자를 내놓으면 수용액 속 양이온 중 환원되기 가장 쉬운 이온(반응성이 가장 작은 금속 이온)부터 먼저 석출된다. 즉 A⁺가 B²⁺보다 먼저 석출되었다면 금속의 반응성 크기는 C > B > A 순이다.

선지 점검 ① “A⁺ 2N개와 B²⁺ 2N개가 든 수용액에 C를 넣어 모두 반응시키면 C³⁺는 2N개이다.” → [적절 ○]

초기 양이온 총 전하량은 (+1)×2N + (+2)×2N = +6N 이므로, 완결 후 C³⁺만 존재할 때 (+3)×n = +6N 에서 즉시 2N개로 확정된다.

선지 점검 ② “그래프의 세로축이 ‘전체 이온 수’일 때도 기울기만으로 전하량 비를 바로 읽는다.” → [부적절 ×]

전체 이온 수에는 반응하지 않는 구경꾼 음이온(NO₃⁻ 등)이 포함되어 있으므로 음이온 수를 제외한 순수 양이온 수의 비로 계산해야 한다.
