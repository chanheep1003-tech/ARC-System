## 1. DESIGN PHILOSOPHY — 1-PERSON DEEP SELF-STUDY EDITION
`ARC CORE` is a high-readability, high-depth self-study concept & discrimination book in pure black-and-white (`Pure B&W`), visually unified with `ARC N°` and `ARC FINAL`.
- Remove unnecessary beginner blanks, empty memo margins, 4-sided black box clutter, and repetitive navy/burgundy color boxes.
- Prioritize deep conceptual mechanisms, quantitative derivations, edge-case exceptions, and school-level proposition discrimination in an airy, book-grade open layout.

## 2. PRODUCT ISOLATION & PDF QC INVARIANTS (UNCHANGED)
- Layout Mode: `ONE_COLUMN` (`CORE_TWO_COLUMN_FLOW = 0`). Main body uses a single wide reading column (`52pt` horizontal margins).
- Typography Floor: Body text target `9.9pt` (`9.6–10.2pt`), line-height `1.62–1.65`, Pretendard / Noto Sans KR / Nanum Myeongjo+Gothic Regular (`400`), never Thin/Light.
- No closed 4-sided card clutter; use left vertical accent bars, horizontal hairlines, and Booktabs-style tables.
- Compact side-by-side comparison micro-grids (`core-contrast`) are permitted only for short A vs B contrasts (`<= 6` lines per side) so they never trigger two-column lane flow.
- Forbidden Student Leak Strings: Never stamp internal difficulty badges (`D1`–`D5`) or hype labels (`킬러`, `고난도 배지`) in student text.

## 3. APPROVED VISUAL MODULES
1. **Pure B&W Minimal Cover**: Top institutional rule (`ARC SYSTEM · DONGBUK HIGH SCHOOL`), outlined `ARC CORE` badge, large bold title & course, bottom `동북고등학교`.
2. **Open Chapter Header**: Clean uppercase unit tag, `16pt` Bold chapter title, and a `1.4pt` black bottom rule (zero enclosed box).
3. **Thesis-First Narrative Section (`01`, `02`, ...)**: `11pt` Sans Bold single-sentence proposition heading followed by `9.9pt` Serif explanation (`line-height: 1.62`).
4. **Left-Bar Callout (`.callout-bar`)**: Soft `#F5F5F5` tint + left `2.5pt` solid black bar only (top/right/bottom open) for key formulas, causal chains, or grammatical exception rules.
5. **Booktabs Open Table (`table.core-open-table`)**: NO vertical borders. Top (`1.1pt`), header separator (`0.6pt`), row hairlines (`0.4pt #C8C8C8`), bottom (`0.9pt`).
6. **Borderless Contrast Micro-Grid (`.core-contrast`)**: Top/bottom rules + subtle center vertical divider (`0.5pt`) for direct two-concept contrast (`피동 vs 사동`, `외부 경제 vs 외부 불경제`).
7. **Discrimination Point Callout (`.core-disc`)**: Left `2.0pt` black accent bar + Sans Bold diagnostic title + Serif precision explanation.
8. **Proposition Verification Block (`.core-check`)**: Numbered option statements (`선지 ①/②/③ ... → [정답 ○ / 오답 ×]`) with crisp reasoning separated by thin horizontal hairlines.
