# ARC PAIRED DELIVERY V1.0 — 문제지와 답지는 항상 함께
VERSION_DATE: 2026-09-30 · 출처: 사용자 지시("다음부터 무조건 문제지랑 답지랑 같이 나오도록 조판")

## 규칙 (HARD)
1. **모든 세트(N°, FINAL, 그 외 문항 세트)는 문제지와 답지를 함께 조판·납품한다.** 문제지 단독 납품 금지.
2. 답지 구성
   - N° 계열: **정답표 + 간단 해설**(문항마다 정답·핵심 근거).
   - FINAL 계열: **정답 + 채점 기준**(서·논술형 배점·감점 기준 포함).
3. **합본 PDF를 기본 산출물로 한다**: `…_V{버전}_문제지+답지.pdf` = 문제지 → 정답표 → 해설(또는 정답 및 채점 기준) 순서.
   - 합본에는 PDF 책갈피(문제지/정답표/해설)를 넣고, 문제지 끝이 홀수 쪽이면 백지 1쪽을 넣어 답지가 새 낱장에서 시작하게 한다.
   - 학생 배부용 문제지 단독 PDF와 답지 단독 PDF는 **합본과 함께** 부산물로 두는 것만 허용한다(편의용).
4. 답지의 정답·해설은 문제지와 **같은 빌드**에서 생성한다(같은 `items`·같은 정답 배치 시드). 문제지만 다시 빌드하고 답지를 두고 가는 것을 금지한다.
5. 해설은 선지의 원문자(①~⑤)를 인용하지 않고 내용 기준으로 쓴다(정답 위치 셔플 후에도 유효하도록).
6. 납품 점검: 합본 쪽수 = 문제지 + 정답표 + 해설(+백지), 정답표의 문항 수 = 문제 수, 정답 분포(각 번호 균등, 3연속 금지).

## 구현
- 도구: `quality/tools/bundle_pdf.py OUT.pdf 문제지.pdf 정답표.pdf [해설.pdf]`
- 세트별 `src/make.sh` = 빌드 → PDF 3종 → 합본(예: N°11, N°12). 새 세트는 `make.sh`를 복사해 시작한다.
- 기존 세트(N06~N10, FINAL N01·N02)는 PDF 재조판 없이 `bundle_pdf.py`로 합본을 추가해 두었다.
