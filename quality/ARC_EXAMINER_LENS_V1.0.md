# ARC EXAMINER LENS V1.0 — 내신 출제자 시선으로 만들기
VERSION: 1.0
DATE: 2026-11-14
STATUS: ACTIVE-DEV
SCOPE: ARC_N · ARC_FINAL, 모든 활성 과목 (KOR · ENG · SOC · SCI)
GATE: `python tooling/content_qa/examiner_lens_gate.py <번들>/items.yaml`
ROLE FILE: `agents/school-examiner.md`

## 0. 왜 필요한가
지금까지는 "규칙 문서 → 문항"으로 만들었고, 사실성은 작성자가 스스로 체크리스트로 검사했다.
그 결과 정답은 맞지만 "실제로 이렇게 나올 것 같지 않은" 문항이 나왔다 (사용자 피드백 2026-11-14).
내신 교사는 문항을 그렇게 만들지 않는다. 이 문서는 **교사가 실제로 출제하는 순서**를 ARC 제작 순서로 고정한다.

경계: 특정 교사의 개인 성향은 예측하지 않는다 (`teacher_style_prediction: disabled` 유지).
여기서 쓰는 것은 한국 고교 내신 출제의 **공통 관행**과 D1·D2 근거(`quality/school/ARC_SCHOOL_EVIDENCE_LEDGER_V1.0.yaml`)뿐이다.

## 1. 출제 순서 (바꾸지 않는다)
1. **출제 계획표(이원목적분류표)부터.** 문항마다 `단원/성취기준 × 내용 요소 × 행동 영역(지식·이해·적용·분석) × 난도 × 배점`을 먼저 적는다. 문항 문장은 아직 쓰지 않는다.
2. **수업 근거를 고정한다.** 문항마다 "이건 수업 어디서 다뤘나"를 교과서 쪽·학습활동 번호·학습지 항목·판서 포인트로 적는다 (`teaching_anchor`). 근거를 못 대면 그 문항은 내신 문항이 아니다.
3. **학생이 실제로 틀리는 지점에서 시작한다.** 교사는 "학생들이 이 개념에서 어디를 헷갈리나"를 먼저 떠올리고 그 오해를 오답으로 만든다. 오답 4개는 **서로 다른 오개념** 4개다 (`distractor_misconceptions`). 같은 규칙을 네 번 반복한 선지는 오답 1개짜리 문항이다.
4. **발문은 시험지 표준형으로.** 예: "윗글에 대한 이해로 적절하지 않은 것은?", "<보기>를 참고하여 ㉠~㉤을 설명한 내용으로 가장 적절한 것은?", "다음 자료에 대한 설명으로 옳은 것만을 <보기>에서 있는 대로 고른 것은?"
5. **예문·지문은 교사가 시험지에 실제로 쓸 문장으로.** 교과서·학습지·실제 용례(신문, 문학 작품, 사전 용례)에서 온 듯한 문장. 상황을 억지로 지어낸 감탄문·대화체 예문은 쓰지 않는다.
6. **이의 제기(민원) 검토를 통과해야 한다.** 내신 교사에게 가장 중요한 것은 기발함이 아니라 **정답 시비가 없는 것**이다 (§3).
7. **동료 교사 검토** — `agents/school-examiner.md` 역할이 정답을 모르는 상태로 시험지만 읽고 KEEP / REWRITE / DROP을 판정한다 (§4).

## 2. 시험지 표기 규약
- 대상 표시는 밑줄, ㉠~㉤, ⓐ~ⓔ, [A]~[C] 구간 표시를 쓴다. 단어를 `[만]`처럼 대괄호로 감싸 표시하지 않는다 (`NON_SCHOOL_MARKUP`).
- 선지 길이를 고르게 한다. 정답이 늘 가장 길고 가장 친절한 문장이면 안 된다 (`LONGEST_ANSWER_CUE`).
- 세트 안에서 정답 번호가 한쪽에 몰리지 않게 한다 (`ANSWER_POSITION_SKEW`).
- 판단축·근거 범위·정답 후보·추론 단계·second-best·distractor 같은 제작 용어는 학생용 문장에 쓰지 않는다 (`META_LANGUAGE_LEAK`).
- 선지는 지문 등장 순서나 길이 순서처럼 학교 시험에서 흔한 순서로 배열한다.

## 3. 이의 제기 검토 (APPEAL CHECK)
문항마다 다음을 `appeal_check`에 기록한다. 하나라도 걸리면 고친다.
- 교과서·학습지·수업 밖 지식이 있어야 풀리는가?
- 다른 선지도 정답이라고 주장할 여지가 있는가? (사전·규범·교과서 서술이 엇갈리는 경우 포함)
- 발문의 "적절한/적절하지 않은", "옳은/옳지 않은"이 선지 전체에 한 가지 뜻으로만 읽히는가?
- 지문·<보기>에 없는 정보를 정답 근거로 쓰는가?

## 4. 동료 교사 검토 판정 코드
| 코드 | 뜻 |
|---|---|
| `NOT_TAUGHT` | 수업 근거를 댈 수 없다 |
| `APPEAL_RISK` | 복수 정답·정답 시비 여지 |
| `AWKWARD_SENTENCE` | 교사가 시험지에 쓰지 않을 어색한 문장·예문 |
| `NON_EXAM_FORMAT` | 실제 학교 시험지에서 보지 못하는 발문·표기·배열 |
| `CLONE_DISTRACTORS` | 오답들이 같은 오개념의 반복 |
| `SURFACE_CUE` | 길이·어조·극단어 등 내용 밖 단서로 풀린다 |
| `POSITION_MISMATCH` | 계획표 난도와 실제 체감 난도가 다르다 |

판정은 문항별 `KEEP / REWRITE / DROP`과 코드, 한 줄 사유. 세트 기준: DROP + REWRITE가 30%를 넘으면 세트를 사용자에게 보여 주지 않고 다시 만든다.

## 5. 번들 필드 (items.yaml)
번들 최상위에 `examiner_lens: V1.0`을 적으면 아래 필드가 필수다. 적지 않은 기존 번들은 표기 규약(§2)만 검사한다.
```yaml
examiner_lens: V1.0
items:
  - item_id: …
    blueprint: {unit: "3-2", content: "띄어쓰기-의존명사", behavior: 적용, difficulty: D3, points: 3.5}
    teaching_anchor: "교과서 p.118 학습활동 2 / 학습지 3번"
    distractor_misconceptions:      # 선택형: 정답이 아닌 선지마다 하나, 모두 달라야 함
      1: "시간 경과 '만'을 보조사로 착각"
      3: "관형사형 뒤 '뿐'을 조사로 착각"
      4: "…"
      5: "…"
    appeal_check: PASS              # 또는 걸린 항목 설명
```

## 6. 다른 규칙과의 관계
- `ARC_KOREAN_EXAM_REALISM_GATE_V1.0`의 AI 문체 차단 규칙은 그대로 유효하다. 이 문서는 그 앞단(만드는 순서)과 뒷단(교사 검토)을 추가한다.
- `ARC_SCHOOL_ARCHETYPE_GATE_V1.0`의 원형 선택이 §1-1 출제 계획표의 행동 영역·형식 칸을 채운다.
- 이 게이트 PASS는 내용 검증이 아니다. 독립 재풀이와 사용자 검수는 그대로 필요하다.
