# ARC 행 인용 볼드 규칙 V1.0

**규칙**: 문항의 발문·<보기>·선지가 "N행", "N~M행"처럼 행 번호로 본문을 가리키면, 그 문항이 속한 지문의 **해당 행 전체를 굵게(볼드) 표시**한다.

- 적용 대상: 행 번호가 붙는 운문(`poem`, `stanzas`). 행을 인용하는 문항은 행 번호가 있는 지문에서만 출제한다(산문·논설문은 '문단'으로 가리킨다).
- 한 지문에 여러 문항이 행을 인용하면 인용된 행의 합집합을 볼드로 한다.
- 인용 행을 뽑는 도구: `quality/tools/line_cite.py`의 `cited_lines()`. 빌드 스크립트가 이를 호출한다.
- 볼드는 본문에서 위치를 찾게 해 주는 장치일 뿐이므로, 볼드로 정답 단서가 되지 않게 ㄱ~ㅁ 보기처럼 여러 행을 함께 인용하는 문항에서는 모든 인용 행을 같은 굵기로 표시한다.
- 인용한 행 번호가 지문의 실제 행 수를 넘으면 빌드가 실패한다(오기 방지).
- 적용 세트: N°13부터. 이전 세트(N06~N12, FINAL)는 개정 시 같은 방식으로 소급한다.
