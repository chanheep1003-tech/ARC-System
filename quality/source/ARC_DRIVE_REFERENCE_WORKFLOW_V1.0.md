# Drive 자료 기반 출제 운영 V1.0
상태: 개발 브랜치 후보. 이 문서는 원본 Drive 자료를 실제로 읽는 호스트가 실행하는 절차이며 파일 자체는 Drive를 검색하거나 모델을 학습시키지 않는다. 기존 출제 출처 정책, 범위 게이트와 검수 게이트에 추가 적용한다.

## 매 출제 시
1. 고정된 manifest와 사용자 요청에서 과목, 학년, 단원, 시험범위, 문항 수와 수준을 확정한다. 다른 학기 기출의 범위는 가져오지 않되 형식 분석에 활용할 수 있다.
2. 연결된 Drive에서 학교 원안·교과서·학교 학습지·공식 규정·기존 ARC N°·문제집/모의고사 및 해설을 검색한다. quality/source/ARC_DRIVE_DONGBUK_REFERENCE_20261107.md는 시작점이며 전체 목록이 아니다. 과목별 가용 자료를 실제 검색하고 미검색/미열람을 분리한다. 기존 N°는 중복과 개선점 검토용이며 정답 검증 자료로 무조건 신뢰하지 않는다.
3. 각 후보는 Drive 파일 ID, 제목, 수정시각/버전, 과목·학년·범위, 자료 유형을 기록한다. 제목만 확인한 자료는 DISCOVERED, 본문과 해당 지점까지 실제 확인한 자료는 READ, 원본·유효범위·권리 확인이 남으면 HOLD로 남긴다. 본문을 받지 못했거나 표·그림·수식이 추출되지 않았다면 해당 부분은 읽었다고 주장하지 말고 원본 확인 전 HOLD한다. 내용 확인 전 원본 문제의 변형이나 학교 기출 근거로 쓰지 않는다.
4. 학교 출제 근거는 과목·학년·시험별로 구분하고 확인한 시험/문항/쪽을 남긴다. 출제자가 같은 유형을 모두 따른다고 예언하지 않는다. 교과서·학습지와 현재 시험 범위 우선. 맞춤법은 인박스의 국립국어원 해설을 찾아 관련 항목을 읽고 규정과 현행 사전 및 교과서와 대조한다. 옛 발간본만으로 현재 규범을 단정하지 않는다.
5. 기출 원문 및 사설 자료는 Drive에 두고 GitHub에는 식별자·출처·유형 분석·사용 조건만 저장한다. 실질적으로 베낀 문항을 새 창작으로 표기하지 않는다. 원문 복제·공유·이용 허용 여부를 확인하고 제한이 있거나 불확실하면 생성물에 싣지 않는다. 사설 모의고사는 학교 실제 기출과 구별하고 학년·범위에 맞는 사고 방식만 참고한다.
6. 70% 기출·검증된 기출 변형 / 30% 창작 목표는 검증된 출처가 충분할 때만 적용한다. 진짜 기출/원본과 수정 사항을 식별할 수 없는 문항은 기출 변형으로 계산하지 말고 부족분을 BLOCKED 또는 사용자에게 명시한다.
7. 독립 재풀이와 모든 선지 진위, 단일 정답, 현행 규정·시험 범위·난이도·중복·조판을 검사한다. 문항 해설에 관련 출처와 근거를 연결한다. 정답 미검증이나 실제 시각자료 미확인 시 검수 완료로 취급하지 않는다.

## 배치별 기록 — 단일 실행 상태와 연결
기존 ARC-RUN-V1의 state.json과 함께 배치별 source_receipt.json 및 item_lineage.json을 두고 기존 Drive 커넥터로 실제 저장한다. 한 배치 한 소유자. 구조 예시 (값은 예시이며 작업 성공 증거가 아님):
```json
{"batch_id":"예시","scope":{"subject":"KOR","unit":"한글 맞춤법"},"sources":[{"drive_file_id":"실제ID","version_or_modified":"실제값","kind":"official_explanation","status":"READ","pages_or_sections":["제41항"],"usage":"규정 근거","evidence":"실제 열람 증거"}],"item_lineage":[{"item_id":"Q01","origin":"original","source_refs":["실제ID#제41항"],"transformation":"새 사례 적용","review":"PENDING"}]}
```
origin은 실제 출처에 따라 past_exam, verified_adaptation, original 중 선택한다. 출처 불명은 unknown으로 남기고 기출 비율에서 제외한다. 도출한 오류·약점·중복 패턴 및 수정 이력은 배치 ID와 증거를 붙여 다음 배치의 중복 검사 및 출제 설계에서 참고한다. 민감정보와 저작권 원문을 GitHub에 올리지 않는다. 저장 영수증 없이 Drive 기록 완료를 주장하지 않는다.

## 완료 판단
자료 검색과 열람, 개별 문항 출처, 실제 저장 영수증, 독립 검수는 별개다. 자동 Drive 연동·검색·모델 재학습·차기 세션의 자동 기억은 이 문서만으로 생기지 않는다. 연결된 호스트가 매번 실행하고 실제 저장한 기록을 다시 읽어야 한다.
