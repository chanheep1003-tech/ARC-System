## 2. CURRENT FOUR-PASSAGE AXES

### A. 정훈 「탄궁가」
Priority axes:
- concrete poverty signs vs abstract lament
- lament/resentment -> attempted expulsion of 궁귀 -> acceptance/resignation
- personification/dialogue function
- humor/self-mockery coexisting with suffering
- rhetorical question / concrete enumeration / classical allusion effects
- acceptance of poverty != actual material resolution
- whole-work structure must not be imposed on a partial school excerpt without verification

High-value distractor kernels:
- a real concrete-poverty detail + false claim of successful economic recovery
- a real dialogue device + false claim of social-institutional reform
- a real humorous expression + false inference that suffering disappears
- a real acceptance ending + overstatement as active overcoming

### B. 백석 「팔원 - 서행시초 3」
Priority axes:
- observed fact vs speaker inference/speculation
- present observation vs inferred past labor
- cold/sensory imagery and target hardship
- new clothing vs cracked hands contrast
- observer stance vs direct intervention
- colonial-context implication vs unsupported historical overreach
- window/spatial separation function
- disputed referents must follow school-source wording, not a single external interpretation

High-value distractor kernels:
- accurate observation + falsely upgraded certainty about the girl's past
- accurate colonial clue + unsupported event/motive added
- accurate emotional response + false claim of direct consolation/intervention
- correct sensory device + wrong effect axis

### C. 기형도 「기억할 만한 지나침」
Priority axes:
- past encounter vs present recollection
- structural parallel between past solitary clerk and present empty office
- glass/window as seeing channel and distance/boundary
- staying until the crying stops != solving or directly intervening
- snow/space imagery across time layers
- '희고 거대한 서류 뭉치' and bureaucratic/dehumanized spatial impression
- final double negative and empathetic/affirming judgment
- similar situation/identification != identical cause/emotion

High-value distractor kernels:
- true empathy + false direct intervention
- true temporal parallel + false claim of identical events
- true office imagery + false literal workload interpretation
- true identification + overclaim of complete experiential identity

### D. 칸트·헤겔 자율성 독서
Priority axes:
- autonomy vs arbitrary choice
- Kant: maxim / universality / self-legislation / heteronomy
- distinction between source position and later scholarly critique
- Hegel: abstract freedom vs concrete freedom
- social institutions as conditions of concretized freedom, not merely external restraint
- family / civil society / state relations when they are actually present in the tested excerpt
- common core vs different realization conditions
- application of Kant/Hegel to cases without importing outside philosophy-history detail

High-value distractor kernels:
- correct self-legislation wording + arbitrary-choice substitution
- correct social-institution reference + unconditional obedience overstatement
- correct commonality + swapped difference axis
- correct Kant term paired with Hegel realization condition or vice versa
- critique/implication misattributed as explicit philosopher position
