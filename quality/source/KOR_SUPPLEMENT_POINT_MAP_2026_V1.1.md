## 2. PRIORITY MATRIX

### A. 정훈 「탄궁가」
P0 axes:
- 극심한 생활고의 구체성: 끼니·의복·농사·취사·제사·손님 접대 등
- 궁귀 의인화와 대화 구조
- 한탄/원망 -> 축출 시도 -> 궁귀의 항변 -> 체념적 수용
- 결말의 수용 != 경제적 문제 해결
- 표면적 수용과 현실 비판적 인식의 공존

P1 axes:
- 고사 활용과 비교 효과
- 대구/유사 통사 반복
- 봄·풍년·따뜻한 겨울의 기대 좌절
- 사회적 부담과 개인 궁핍의 연결
- 해학성/생동감과 비애의 공존

High-value near-miss distractors:
- 구체적 생활고는 맞지만 '경제적 회복'으로 결론
- 궁귀와의 대화는 맞지만 '사회제도 개혁'으로 기능 과장
- 해학성은 맞지만 '고통 소멸'로 과장
- 수용은 맞지만 '적극적 극복/안빈낙도 완성'으로 절대화
- 사회 구조 언급은 맞지만 개인 생활고와의 관계를 단일 원인으로 단정
- 봄/풍년/따뜻한 겨울을 실제 풍요의 실현으로 오독

Conditional:
- 「이존당기」 비교는 실제 시험/학교 자료에 포함된 비교축일 때만 사용

### B. 백석 「팔원 - 서행시초 3」
P0 axes:
- 관찰된 사실 vs 화자의 추측
- 현재 관찰 vs 추정된 과거 노동
- 새 저고리 vs 터진 손등의 대비
- 유리창 = 경계 + 관찰 매개
- '어느 한 사람'의 화자 객관화
- 직접 위로/개입이 아닌 관찰·상상·공감

P1 axes:
- 차가운 아침/촉각 이미지
- 현재형 서술의 생생함
- 구체적 지명·거리의 막막함
- 식민지 표지의 맥락
- 노동 열거의 구체성
- 개인 연민에서 역사적 현실 인식으로의 확장

High-value near-miss distractors:
- 실제 관찰 정보 + 과거 노동을 '확인된 사실'로 승격
- 유리창의 단절 기능은 맞지만 매개 기능을 제거
- 화자의 공감은 맞지만 직접 대화/위로/문제 해결을 추가
- 새 저고리의 색채는 맞지만 행복/풍요의 표지로 단정
- 식민지 맥락은 맞지만 특정 사건/동기까지 외부지식으로 과잉 추론
- 현재형 효과는 맞지만 '긴박한 추격/갈등' 같은 다른 효과로 치환

### C. 기형도 「기억할 만한 지나침」
P0 axes:
- 1연 과거 목격 vs 2연 현재 회상/성찰
- 현재 자신과 과거 사내의 동일시
- 과거/현재를 겹치는 유사 통사 구조
- 유리창 = 관찰 매개 + 물리적 거리
- 떠나지 않음/지켜봄 != 직접 해결/위로
- '희고 거대한 서류 뭉치'의 관료제·비인간성
- 마지막 이중 부정의 조심스럽고 단호한 긍정

P1 axes:
- 눈/어둠/희미한 빛의 공간 분위기
- 침묵의 의인화
- 무력감과 공감의 중첩
- 제목 '지나침'의 우연성 vs 기억 가치의 긴장
- 유사 상황 != 동일한 원인·감정의 완전 일치

High-value near-miss distractors:
- 공감/연대는 맞지만 직접 개입·해결을 추가
- 과거/현재 병치는 맞지만 사건이 동일하다고 단정
- '서류 뭉치' 비유는 맞지만 실제 업무량의 문자적 묘사로 축소
- 동일시는 맞지만 구체적 사연까지 완전히 같다고 과장
- 현재 화자의 유사 상황은 맞지만 '현재 실제로 울고 있음'을 명시 사실로 승격
- 제목 해석에서 '도덕적 지나침' 하나로만 환원

### D. 칸트·헤겔 자율성 독서
P0 axes:
- 자유/자율 vs 자의적 선택
- 칸트: 현상계/예지계, 타율, 준칙, 보편성, 자기입법, 도덕 법칙
- 헤겔: 추상적 자유 vs 구체적 자유
- 법·제도 = 단순 외적 억압이 아니라 자유의 구체화 조건
- 가족 -> 시민 사회 -> 국가의 관계망 확대와 안정성
- 칸트와 헤겔의 공통점/차이
- 사례 적용에서 판단 기준의 정확한 귀속

P1 axes:
- 감각 욕구에 따른 행위와 타율
- 보편성 검사와 도덕 법칙의 관계
- 시민 사회의 이해관계 충돌과 국가의 조정
- '제도 자체'와 '제도 부정·선택 가능성 절대화'의 구별
- 원 논문/외부 해설의 확장 내용과 학교 지문 명시 내용의 분리

High-value near-miss distractors:
- 자기입법은 맞지만 자의적 선택과 동일시
- 감각 욕구가 의지를 '규정할 수 없다'고 과도하게 바꿈
- 사회 제도는 맞지만 무조건적 복종으로 절대화
- 가족/시민사회/국가의 기능 또는 안정성 축 교환
- 칸트 용어와 헤겔 실현 조건을 교차 결합
- 철학자의 명시적 입장과 후대 비판/설명을 뒤섞음

SCHOOL_SOURCE_VERIFY_REQUIRED before answer-basis use:
- 공익 신고 사례의 세부 설정
- 가족/시민 사회/국가의 구체 사례
- 원 논문의 세부 논증
- 외부 해설이 추가한 철학사 배경

## 3. CROSS-PASSAGE MATRIX

### 「팔원」 vs 「기억할 만한 지나침」
Shared:
- 고통받는 타인의 관찰
- 거리/경계 장치
- 연민·공감
- 직접적 문제 해결은 아님

Critical differences:
- 「팔원」: 외양/상황 관찰 -> 과거 노동 추측
- 「기억할 만한 지나침」: 현재의 유사 상황 -> 과거 인물 회상/동일시
- 두 작품의 유리창은 모두 관찰 매개가 될 수 있으나 동일한 상징 기능이라고 자동 처리 금지
- 「팔원」의 추측과 「기억할 만한 지나침」의 동일시를 서로 바꾸는 선지는 고가치 오답 후보

### 칸트 vs 헤겔
Shared:
- 자유를 무제한 욕망 충족으로 보지 않음

Difference:
- 칸트: 이성적 자기입법/보편성/도덕 법칙
- 헤겔: 사회 관계와 제도 속에서 구체화되는 자유

High-value application traps:
- 같은 사례에 칸트의 보편성 검사와 헤겔의 제도적 실현 조건을 교차 귀속
- '법/제도 존재'만으로 헤겔적 자유가 자동 성립한다고 과장
- '자율'을 단순 선택 가능성으로 축소

### Four-passage integration
BACKGROUND/INTEGRATION_ONLY unless school source explicitly supports:
- 개인의 고통과 사회·역사·제도 현실의 관계
- 인식 변화/이해 심화
- 개인과 외부 현실의 긴장

Do not use broad four-passage themes as the sole correct-answer basis unless the exact comparison is evidenced in the tested materials.

- SCOPE_OVERREACH
- DEGREE_ABSOLUTIZATION

- CONDITION_PARTIAL_MATCH
- FUNCTION_SINGLE_SIDED_REDUCTION
- OBSERVATION_IDENTIFICATION_SWAP
- SOCIAL_CONTEXT_OVERDETERMINATION

Strong distractor rule:
- TRUE_KERNEL must be source-supported
- only one or a tightly coupled set of decisive distortions should make it false
- the error must require passage evidence, not mere common sense, to reject
- wording/detail level should match the correct option

## 6. PRACTICAL STUDY/QA SIGNAL
When reviewing a generated set, use the same discipline recommended in SOURCE_C:
- do not memorize only the key
- identify the one word/condition changed in each wrong option
- classify whether the wrongness is FACT / INFERENCE / TIME / AGENCY / SCOPE / EFFECT / CONCEPT / DEGREE

This rule is useful both for student review and for ARC distractor QA.
