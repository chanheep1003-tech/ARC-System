## 4. 단원별 출제 공식 (분석 문서 §2 — 올해 범위에 실제로 들어간 단원만 쓴다)
### 산·염기와 중화 반응, 발열·흡열 (작년 기말 7문항 25점)
- 지시약 색(페놀프탈레인·BTB·메틸 오렌지), 전기 영동(KNO₃ 거름종이: H⁺는 (−)극, OH⁻는 (+)극 — 반대로 속이는 함정).
- **입자 모형·이온 수 상댓값**으로 고난도: 혼합 용액 이온 2종이면 중성, 3종이면 산성·염기성 / 생성된 물 분자 수 = 적게 든 H⁺·OH⁻ 수 / 1가 산에 1가 염기를 넣을 때 중화점까지 전체 이온 수 일정 / **실제 이온 수 = 단위 부피당 이온 수 × 전체 부피**(부피를 곱하지 않게 유도하는 D5 함정).
- 최고 온도 지점 = 중화점, 전체 부피가 작을수록 온도 변화 큼, 앙금 생성 중화(BaSO₄)는 중화점에서 전기 전도도 거의 0.
- 서답형 실제 예: 최고 온도 곡선 A~D 지점의 Na⁺/Cl⁻ 수 비와 구경꾼 이온 원리 서술.
### 생태계·에너지 흐름·태양 에너지 (작년 기말 9문항 31.8점)
- 생물/비생물 요소, **작용(비생물→생물) vs 반작용(생물→비생물) vs 상호작용** 3분할(지렁이 토양 변화 = 반작용; 버섯·곰팡이 = 분해자).
- 포식-피식 주기 그래프(피식자 먼저 증가), 에너지 효율 = 현 단계/이전 단계 × 100(상위로 갈수록 효율은 커질 수 있음).
- 태양 수소 핵융합 → **질량 결손**(질량 증가 X), 지열·조력·원자력은 태양 에너지 기원이 아님.
