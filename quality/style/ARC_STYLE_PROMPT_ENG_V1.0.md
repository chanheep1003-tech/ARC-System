## 4. 유형별 출제 공식
### 4-1. 어휘 1~10번
- 범위 단어(해커스 Day 31~40)를 **교과서 본문과 다른 새 문장**에 넣는다. 본문 문장을 그대로 쓰면 암기로 풀린다 → 금지.
- 선지 ①~⑤의 **품사·굴절형(-ed, -s, -ly)을 똑같이** 맞춘다. 어형만 보고 지울 수 있으면 실패.
- 단서는 **전치사 연어**(absorbed in, with the advent of)와 **대조·인과 연결**(Although ~, everyone could tell ~)로 준다.
- VOC-02 함정: 철자가 비슷한 혼동어(complement/complete, currency/current)를 선지에 꼭 넣는다. 두 문장의 시제·수가 다르면 `_____s`, `_____(e)d` 어미 힌트.
- VOC-03 오답 3원칙: ① 반의어의 영영풀이 ② 어근 착시(uneasy → "not easy") ③ 다의어의 다른 문맥 뜻(crude, gross).
- VOC-04: 정답 쌍은 문맥 속 뜻(gross weight = whole, substantial = considerable).

### 4-2. 어법 18~21번 (GRM-01) — 동북고 다섯 포인트(출제 순위대로)
1. **주어-동사 수일치** — 수식어구·관계절로 핵심 주어를 숨긴다 (Tackling these tasks … ④ are → is).
2. **정동사 vs 준동사 / 분사 능동·수동** (the researchers ② asking → asked; data ④ providing → provided).
3. **관계대명사 vs 관계부사 / 동격 that** (⑤ which → where; the message ④ who → that).
4. **대명사 수일치** (that vs those, its vs their).
5. **형용사 vs 부사** (eager → eagerly; reported → reportedly).
- 한 문항의 다섯 밑줄은 서로 다른 포인트. 정답(틀린 것)은 하나, 나머지 넷은 **헷갈리지만 맞는** 표현.

### 4-3. 교과서 다중 어법 23번 (GRM-02) — 동북고 시그니처
- **Lesson 2 본문 핵심 단락 하나**에서 (a)~(g) **문장·절 전체에 밑줄**(단어 하나가 아니라). 7개 중 **3개만 원문 그대로**, 4개에 미세 오류를 하나씩 심는다.
- 실제 변형 기법: 수동 부정사를 능동으로(had to be done → had to do), every + 복수(every years), and + 관계대명사(and some of which), 전치사 + if(about if), another/other 혼동.
- 선지는 `(a), (c), (f)`처럼 3개 묶음 5개.

### 4-4. 독해 (N기출 28지문 + 교과서)
- **원문 유형을 그대로 내지 않는다.** 원래 빈칸 문항이었으면 주제·어휘·삽입으로 바꾼다(교차 변형). 원문 빈칸 문장은 **동의어·유의 구문·이중 부정으로 패러프레이징**해서 선지에 둔다.
- RDG-03: 반의어 치환(fewer ↔ more, retains ↔ drains)뿐 아니라 **not 삽입·삭제**로 원문을 외운 학생이 틀리게(For Kant, it is not ④ essential …).
- RDG-05: 핵심 소재 단어는 그대로 쓰되 논지가 벗어나는 문장을 ③이나 ④ 위치에.
- RDG-07: However, Instead, This/These + 명사, 비교급(Even more significant) 문장을 빼서 낸다.
- RDG-08 불일치: **한글 선지**, 세부 인과·수치·조건을 비튼다.
- RDG-01: 주제·제목 **영문 선지 100%**, 요지는 영문 문장 선지 절반 이상.
- RDG-09(34번): 지문 아래 ⇩ 박스에 1문장 요약, (A)-(B) 영단어 순서쌍 5개.

## 6. 서답형 설계·채점 (부분점수 기준을 해설지에 반드시 적는다)
- **CRQ-01 요약문(서답 1)**: `<조건>` 문구 그대로 — "본문에 있는 단어만을 사용하되 요약문에 언급된 단어는 사용하지 말 것 / 필요한 경우 어형을 변화시킬 것 / 각 빈칸에 한 단어씩". 요약문 구조상 **본문의 형용사·동사를 명사·분사로 바꿔야만** 문법이 맞도록 설계(objective → objectivity, distorted → distortion, computer → computerized). **어형 미변환 시 50% 감점**.

- **CRQ-03(서답 2-2·3·4)**: `<보기>` 어구를 슬래시(/)로 나열, "주어진 어구를 모두 한 번씩만 사용할 것 / (필요하면) 어형을 바꿀 것". 평가 포인트는 전치사 + 동명사 수동(instead of being overly obsessed with), without + having to, 조동사 시제 일치.
