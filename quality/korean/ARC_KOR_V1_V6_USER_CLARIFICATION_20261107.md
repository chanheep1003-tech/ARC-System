# 고1 국어 V1~V6 출제 기준

기준일: 2026-11-07. 사용자 답변으로 확정한 목적과 이를 실행하기 위한 기준을 기록한다. 적용 과목은 국어이며 모든 버전은 사용자가 지정한 시험 범위 안에서 제작한다.

## 버전별 목적

| 버전 | 핵심 목적 | 자료와 문항 구성 | 통과 기준 |
|---|---|---|---|
| V1 | 교과서 중심 전범위 학습 | 지정 범위의 개념·작품·읽기 활동을 골고루 출제한다. 기본 확인과 적용을 함께 둔다. | 범위표에서 빠진 주요 학습 요소가 없고 특정 단원에 불필요하게 편중되지 않는다. |
| V2 | 내신 중요 부분 집중 | 같은 범위에서 실제 학교자료·기출상 비중이 높거나 중요한 부분에 문항을 더 배정한다. V1보다 난도와 추론 과업을 더 섞는다. | 집중 배정의 근거가 있고, 중요 개념을 반복하더라도 판단 과정과 오답 원인이 달라야 한다. |
| V3 | 처음 보는 지문 대응 | 문법·문학·비문학 모두 새로운 자료와 지문을 활용한다. 노래 가사·시·소설·대화 등 장르를 다양하게 고른다. | 새 지문을 읽고 판단해야 풀린다. 지문을 없애도 풀리는 장식적 외부 자료는 탈락한다. |
| V4 | 학교 상위 변별 문항 대비 | 동북고 실제 시험의 상위 변별 수준까지 근거 연결·조건 구별·선지 검증을 훈련한다. | 실제 학교 상위 문항과 요구하는 사고를 비교할 수 있어야 한다. 불필요한 규정 암기·대학 수준 지식으로 난도를 만들지 않는다. |
| V5 | 실제 시험 한 회 리허설 | 지정 시험 범위 전체를 담은 실제 시험 1회분. 확인한 시험의 문항 수·유형·배점·시간·분량·난도 분포를 반영한다. | 부분 단원 문제 모음이 아니라 한 회 시험으로 응시할 수 있어야 한다. 실제 확인하지 않은 형식을 임의로 확정하지 않는다. |
| V6 | 낯선 내용 노출과 문법 판단 | 범위 내 생소한 단어·표현·문장을 폭넓게 접하며 배운 문법으로 판단한다. 한글 맞춤법뿐 아니라 지정 범위의 다른 문법 영역에도 적용한다. | 어휘·문맥의 새로움이 실제 판단에 쓰이며, 일부 품사나 띄어쓰기 유형에 치우치지 않는다. |

## V1: 교과서 중심, 전체 범위를 골고루

- 제작 전에 단원·작품·개념별 범위표를 만든다. 교과서와 사용자가 지정한 보충 범위를 기준으로 빠짐을 확인한다.
- ‘골고루’는 페이지마다 같은 문항 수라는 뜻이 아니다. 학습 요소의 크기에 맞게 배정하되 작은 부분도 통째로 누락하지 않는다.
- 작품 내용 확인, 개념 구별, 근거 찾기, 기본 적용 등 다양한 유형을 둔다. V1이라는 이유로 단순 암기나 쉬운 문항만 만들지 않는다.
- 해설은 교과서 학습 내용과 각 선지의 판단 근거를 연결한다.

## V2: 중요한 부분에 집중하고 추론을 더 섞기

- V1과 같은 지정 범위를 사용하되 배분을 달리한다. 실제 기출, 학교 학습지, 수업 자료에서 확인되는 중요도와 교육과정의 핵심 개념을 근거로 삼는다.
- 두 자료의 비교, 조건을 바꾼 사례 적용, 부분적으로 맞는 선지 검증, 둘 이상의 근거 연결을 V1보다 더 섞는다.
- ‘중요하다’는 설명 없이 임의로 문항 수를 늘리지 않는다. 기출 한 회의 사례를 학교 전체 빈출 비율로 확대하지 않는다.
- V1과 단어만 바꾼 반복 문제로 구성하지 않는다. 같은 개념도 다른 오개념과 사고 동작을 겨냥한다.

## V3: 새 지문을 읽는 능력

- 문학은 처음 보는 시·소설·가사 등에서 표현, 정서, 화자, 서술, 주제 등을 판단한다. 필요한 경우 범위 내 교과서 작품과 비교한다.
- 비문학은 새 글의 정보 관계, 논증, 사례, 조건을 읽고 적용한다. 전문 배경지식은 지문 밖에서 따로 요구하지 않는다.
- 문법은 새 노랫말·대화·문장·문헌 등에서 지정 범위의 문법 현상을 찾아 해석한다. 중세국어는 판본과 시기, 전사를 확인한다.
- ‘모든 장르를 한 세트에 반드시 하나씩’이라는 고정 할당은 두지 않는다. 해당 범위의 학습 요소에 맞춰 자료 종류를 다양화한다.
- 외부 작품은 원문과 이용 가능 범위를 확인한다. 창작한 문장은 실제 작품·가사로 표시하지 않는다. 문학적 표기를 무조건 맞춤법 오류로 단정하지 않는다.

## V4: 동북고 상위 변별 수준까지

- 상한은 실제 동북고 시험의 상위 변별 수준이다. 학교 시험보다 무조건 더 어렵게 만드는 버전으로 운영하지 않는다.
- 길이보다 사고의 질을 조절한다. 여러 조건의 적용 범위를 구별하거나, 선지의 맞는 부분과 틀린 부분을 나누어 판단하게 한다.
- 모든 문항을 최고 난도로 채운다는 고정 규칙은 두지 않는다. 문항의 사고 과정과 학교 근거를 보고 난도를 판단한다.
- 표현의 모호함, 범위 밖 학술 지식, 불필요한 계산량·독해량을 난도라고 부르지 않는다.

## V5: 지정 시험 범위 전체의 실전 한 회

- 한 회 전체를 설계한 뒤 문항을 배치한다. 범위 배분, 지문 순서, 쉬운 문항과 변별 문항의 위치까지 검토한다.
- 선택형·서답형 수, 배점, 시험 시간, 지면 분량은 해당 시험과 관련된 실제 자료를 확인한다. 모르는 값은 확인 필요로 표시한다.
- 학기·범위가 다른 시험들의 문항 수를 평균하여 템플릿으로 만들지 않는다.
- V4보다 항상 어렵지 않다. 실제 시험에 있는 기본 확인 문항도 실제 비중에 맞게 포함한다.

## V6: 낯선 내용에서 판단하는 문법 훈련

- 핵심 목표는 생소한 단어·표현·문장을 많이 접하고, 낯선 상황에서도 문법적 판단과 사고를 해 보는 것이다.
- 한글 맞춤법의 띄어쓰기·사이시옷·표기·품사뿐 아니라, 사용자가 지정한 다른 문법 영역에도 적용한다. 범위 확대는 금지한다.
- 문제 앞에서 개별 단어의 뜻·품사·실제 발음을 일괄 설명하지 않는다. 문장과 문맥을 보고 판단하게 한다. 이런 정보를 미리 주지 않았다는 이유만으로 문항을 탈락시키지 않는다.
- 실제 시험 과업상 필요한 일반 규정·자료 보기는 사용할 수 있다. ‘보기 금지’가 아니라 ‘어휘별 정답 단서를 관행적으로 먼저 풀어 주지 않기’이다.
- 해설에서 어휘의 뜻, 품사, 단어 구성, 규정, 바른 표기, 오답 이유를 확인한다. 사전상의 사실과 규정의 적용 근거를 구분한다.
- 낯선 단어를 안다는 사실만으로 고난도라고 부르지 않는다. 여러 문맥의 구별, 규정의 적용 조건, 선지 검증 등 실제 사고 부담을 함께 본다.
- 낯섦 자체는 목표의 일부이지만 자의적으로 만든 비표준어, 불확실한 규범, 고1 범위 밖 전문지식에 정답을 의존시키지 않는다.
- 문법 영역을 적절히 고루 배분한다. 기존 ‘100문항 중 띄어쓰기 65, 조사·의존 명사 30’은 공통 의무 비율로 사용하지 않는다. 매 제작의 지정 범위에 맞춰 배분표를 새로 작성한다.
- V3와 구별할 때에는 길이만 보지 않는다. V3는 새 지문을 읽고 범위의 문학·비문학·문법을 적용하는 능력, V6는 생소한 언어 표현의 폭을 넓히며 문법적으로 판단하는 능력에 중심을 둔다.

## 같은 학습 요소를 버전별로 구성하는 방법

예: 지정 범위에 의존 명사와 조사 구별이 포함된 경우. 아래는 고정 출제 문항이 아니라 설계 예시이다.

| 버전 | 구성 예 |
|---|---|
| V1 | 교과서의 구별 원리를 확인하고 전체 다른 학습 요소와 균형 있게 배치한다. |
| V2 | 학교자료에서 강조된 구별 축에 문항을 더 배정하고, 여러 조건을 섞어 판단한다. |
| V3 | 새 일기·대화 등 실제 지문의 문맥을 읽고 관련 표현을 분석한다. |
| V4 | 동북고 상위 문항 수준에서 문맥·결합 관계·허용형을 함께 검증한다. |
| V5 | 실제 시험 한 회의 범위 배분과 문항 유형에 맞춰 필요한 수만 포함한다. |
| V6 | 익숙하지 않은 실제 단어와 구성을 다양하게 접하게 하고, 배운 원리로 단어 경계와 기능을 판단한다. |

## 제작 공통 기준과 현재 적용

- V번호는 제작 목적이며 단순한 난도 순서나 파일 개정 차수가 아니다. 문항 수와 D난도는 제작 요청별로 별도 지정한다.
- 이번 요청은 한글 맞춤법 V6 50문항, D3~D5이다. 현재 새 예시 3문항은 방향 확인용이며 이 난도 분포를 충족한 최종 50문항 세트가 아니다.
- 학생용 문제와 정답·해설을 분리하고 정답을 가린 독립 풀이로 복수정답과 선지 근거를 확인한다. 내용 승인과 조판 검수는 별개로 기록한다.
- 기존 V1~V3 PDF에서 확인한 글꼴에 맞춰 발문·선지는 Noto Sans CJK KR 계열, 자료 상자는 Noto Serif CJK KR 계열을 기준으로 시안을 제작한다. 글꼴을 바꾼 새 시안을 확인하기 전 조판 확정으로 표시하지 않는다.
- 이번 답변으로 버전의 기본 목적은 모두 확정되었다. 개별 제작 때 필요한 시험 범위·실제 시험 형식 등 실행 정보가 없다면 해당 정보를 따로 확인한다.
