# ARC 국어 맞춤법·중세 국어 품질 게이트 (2026-11-05)

상태: 개발 브랜치 규정. **정적 검사를 통과해도 600문항 전수 의미 검증이나 최종 배포 승인이 된 것은 아님.**

## 이번 검토로 확인된 재발 위험
1. 한글 맞춤법 제25항의 '1.', '[붙임]', '2.'를 서로 바꿔 인용한 선지·해설이 존재한다. 특히 부사 '곰곰이·더욱이·생긋이·오뚝이·일찍이·해죽이' 등 -이 부사의 원형 표기는 **제25항 2.**에 근거한다. '-하다' 결합 가능성 등 '[붙임]' 사례와 혼동하지 않는다. 명사 '오뚝이'는 제23항과 구별한다.
2. 발음 표기를 단어의 표기와 혼동한 선지(예: 별빛의 잘못된 '[별삳]')가 있다. 국립국어원 표준국어대사전·표준 발음법의 실제 표제어/장단음/된소리 여부를 확인한다.
3. 중세 국어 V3 첫 쪽 목차가 실제 지문군과 다른 오류. 작품별 **창작 시기와 전승 판본의 간행 시기**를 구별하고, 후기 국어 자료를 15세기 국어의 직접 증거로 단정하지 않는다.
4. '적절하지 않은 것' 발문은 **정확히 거짓 하나와 참 넷**이어야 한다. 기존 검증기에서 TRUE 1개로 고정 검증하면 역방향 문제가 잘못 판정된다.

## 필수 문항 검증
- STEP A (출제자): 문항 ID, 원고 SHA256, 실제 원전 위치, 발문 긍정/부정 극성, 의도 정답 번호 및 다섯 선지의 주장별 근거.
- STEP B (독립 풀이자): 출제자 답·난도·A 판단 없이 지문과 중립 출처만 제공. 다섯 선지 각각을 TRUE/FALSE/HALF_TRUE/UNSUPPORTED로 판정하고 자료 페이지·조항의 하위 위치를 지정.
- 적절한 것: TRUE 정확히 1, FALSE 정확히 4. 적절하지 않은 것: FALSE 정확히 1, TRUE 정확히 4. HALF_TRUE나 UNSUPPORTED는 **재작성·보류**. 부정 발문을 단순 “정답 하나” 검사로 처리하지 않는다.
- 연결된 수많은 하위 주장 가운데 한 주장이라도 부정확하다면 전체 선지는 거짓일 수 있다. 출제자의 의도와 무관하게 **모든 비정답 선지가 요구하는 진리값**을 만족해야 한다.
- 어느 한 선지가 명사/부사 등 품사 또는 제25항 하위 항목의 범위를 섞어 주장하면, 원문과 규정의 문장 단위 근거를 제출하지 못할 때 즉시 BLOCKED_RULE.
- 복수정답/복수오답 위험은 ANSWER_KEY 수정만으로 덮지 않으며 질문 원고부터 수정하고 새 SHA에 대해 다시 검수한다.

## PDF·출처 게이트
- 지문 목록은 최종 SOURCE_TEXT_BLOCK ID/실제 제목/수록 범위에서 자동 생성. 첫 장 목차와 본문 실제 표제를 대조한다.
- 옛한글/모음기호/방점/장단음 기호는 텍스트 추출·렌더 이미지 모두 확인. 교정한 글자만 덮었어도 인접 글자와 두 단 조판이 손상되면 BLOCKED_LAYOUT.
- 실제 학교 프린트·교과서·원전 중 승인된 출처만 학생용 원문 근거로 사용한다. 외부 작품의 연대와 원전의 인용 위치를 구분한다.
- 원본 PDF는 삭제하지 않고 구버전 아카이브에서 출처/회귀 기록으로만 보존한다. 새 PDF는 의미 검증 전까지 REVIEW_PENDING, verified item bank/MAIN release 불가.
- 정적 검사: `python tooling/content_qa/korean_norm_regression_gate.py <pdf들>`. 결과 PASS_STATIC_ONLY는 내용 품질 통과가 아니다.
