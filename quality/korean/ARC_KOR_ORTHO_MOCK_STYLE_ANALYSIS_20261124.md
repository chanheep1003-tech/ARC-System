## 2. 모의고사(평가원·학평) 출제 형식 — 6종

색인 88건 분포: 주제 = 한글 맞춤법 일반 60 / 띄어쓰기 18 / 준말 4 / 문장 부호 3 / 사이시옷 3. 학년 = 고1 34 / 고2 15 / 고3 39. 2019년 이후 고1 17건.

**M1 지문 세트형 (2019년 이후 고1의 주류, 고3 언어와 매체 35~36번)**
- 구성: 「[11~12] 다음 글을 읽고 물음에 답하시오.」 설명문이 '제1항 원리(소리대로/어법에 맞도록) → 형태소(실질·형식) → 접미사·합성어에서 원형을 밝히는 조건 → [A] 띄어쓰기' 순서로 전개된다. 그 뒤에 두 문항이 붙는다.
  - ① 「윗글을 바탕으로 <보기>의 ⓐ~ⓔ를 이해한 내용으로 적절하지 않은 것은?」 — <보기>는 일상 문장 1~2개, 밑줄 단어 5개 (2023.9 고1 11번: 쓰러진/작은/마중/끝이/믿음).
  - ② 「[A]를 참고할 때, 밑줄 친 부분의 띄어쓰기가 적절하지 않은 것은?」 — 선지는 짧은 문장 5개 (2023.9 고1 12번: 한번/만난 지도/할 지를/한 번/부지런한지).
- 사이시옷 지문(이감 35~36): '사이시옷은 음운인가'처럼 원리를 묻는 지문이다. 문항은 음운 개수 세기(콧날 = 음운 5개?), 이유 비교(머리말과 머리숱은 사이시옷이 없는 까닭이 다름), 예외 확장(셋방 → 월셋방?)으로 맞춤법을 음운·형태 문법과 묶는다.
- 사용자가 검수에서 통과시킨 골드 예시(2026-11-21)가 바로 이 형식이다.

**M2 규정 제시 + 같은 규정 짝짓기 (수능·모평 B형 고전형)**
- 「~는 ㉠의 '굳이'를 표기할 때 적용된 규정을 따른 것이군」 (2015.9 모평 12번, 2011 수능 12번).
- 핵심 사고: 새 단어가 규정 ㉠/㉡/㉢ 가운데 어느 것에 속하는지를 '같은 근거'로 판정한다. 오답은 이웃 규정과 바꿔 놓은 것(급히 = 제25항인데 제19항의 '굳이'와 짝지음).

**M3 수업·질문-답변·학습 활동 대화형**
- 선생님 설명 → 학생 반응 ㉠ (2016.6 모평 12번 되/돼 → 쐬어라·괴느냐·좨도·봬서·쇄더라도), 인터넷 게시판 Q&A (2015 고1 일찌기/일찍이), 수업 장면 (2019.6 고1 '뿐'·'대로'·'만큼', 2025.11 고1 제1항 ㉠·㉡ 단어 짝짓기).
- 학생이 규칙을 **새 활용형으로 확장**하게 한다. 예시 단어를 다시 확인하는 데서 끝나지 않는다.

**M4 분류표·도식(흐름도)형**
- 2016 수능 12번: 제1항 ⓐ만 / ⓑ만 / 둘 다 충족 × 파생어 / 합성어 표에 예 넣기.
- 2014 수능 11번: 파생어·합성어 × 원형 밝힘 여부 4분류.
- 2026.10 고1 9번: 사이시옷 판단 흐름도의 ㉠~㉢에 '나루+배, 코+날, 존대+말'처럼 **결합식**을 넣게 한다.
- 2025.3 고1 15번: 조건 ㄱ/ㄴ/ㄷ + 「비 + 길 → a [비낄]」처럼 **발음을 주고 표기를 도출**하게 한다. 오답 '위쪽 → 윗쪽'은 뒷말이 원래 된소리인 경우이다.

**M5 사전 자료형**
- 표제어 품사·뜻풀이를 주고 예문 쌍(붙여 씀/띄어 씀)을 판정한다. 2022.9 고1 15번 보다1(동사)/보다2(부사)/보다3(조사) × 예문 ㉠~㉥, 2019.9 고2 12번 '만큼' [Ⅰ]의존 명사 [Ⅱ]조사.
- 사전 지식을 외웠는지 묻지 않는다. **제시된 사전 정보를 문맥에 적용**하게 한다.

**M6 규정 없는 밑줄 표기 판단형** (2015 수능 13번 엇저녁/부치기로/적쟎은/깍뚜기/넙적하게)
- 2015년 이후 고교 모의고사에서는 드물고, 공무원 시험의 주력이다. 내신 연습용 비중은 낮게 둔다.

### 난도를 만드는 장치 (모의고사 공통)
1. **발음 [ ]과 결합식(A+B, 어간+접미사)을 주고 표기를 도출**하게 한다. 완성된 단어를 주고 O/X만 묻지 않는다.
2. **근거 동일성 판정**: 두 단어가 같은 규정을 따르는지, 같은 이유로 사이시옷이 없는지를 묻는다.
3. **예외 경계**: ㄱ·ㅂ 받침 뒤 된소리 / 같은·비슷한 음절의 반복(짭짤하다) / 한자어 6개 / 뒷말이 원래 된소리(위쪽)·거센소리(위층) / 접두사·접미사가 붙은 파생어(해님, 홑이불) / 외래어(피자집).
4. **문법 영역 교차**: 음운 개수, 음운 변동(비음화·ㄴ 첨가), 형태소 분석, 품사(접사·어미·조사·의존 명사)와 묶는다.
5. 선지 문체: 「~겠군 / ~것이군」 추론형. 규정 번호보다 <보기> 안의 기호(㉠, ⓐ)로 연결한다.
6. 발문 극성: 「적절하지 않은 것은?」이 다수. 「있는 대로 고른 것은?」 조합형은 고난도 자리에 둔다.

## 3. 참고서(족보닷컴 미래엔 3단원) — 내신 연계형 스타일
- 한 권 20문항(최상위 15문항)이고 3단원 (1) 중세국어와 (2) 한글 맞춤법이 반반이다. 12권 합계 맞춤법 약 108문항.
- 발문 극성: 긍정 60 / 부정 38 (추출 98문항 기준).
- 주제 빈도(문항 본문 기준, 중복 포함): 띄어쓰기 43, 된소리(제5항) 43, **두음 법칙(제10~12항) 37**, 총칙·형태(제1·19~25항) 34, 사이시옷 33, -이/-히·구별 표기(제51·56·57항) 21, 준말 12.
- 형식 특징:
  - 한 <보기>에 여러 조항을 섞는다(제5항 + 제11항 + 제30항).
  - (담북/담뿍)처럼 괄호 안에서 표기를 고르게 한다.
  - ∨로 띄어쓰기 자리를 표시하게 한다.
  - 학생 답안을 채점하게 한다.
  - 흐름도 판별, 사전 표제어 제시형(뿐1/뿐2)을 쓴다.
  - '있는 대로 고른 개수는?'도 쓴다.
- 품질 주의: 문제집 해설·선지에 오류가 있다(최다빈출01 14번 해설 '콧날은 자음 ㅅ으로 끝나므로', 최다오답04 19번 선지 배열 혼입). **문항 참고용으로만 쓰고, 정답 근거는 규정 원문과 교과서로 검증한다.**
