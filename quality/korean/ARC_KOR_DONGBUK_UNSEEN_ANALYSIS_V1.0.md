| 선택 10 | **여러 사이시옷 합성어**를 3가지 발음 조건에 분류하는 2개 보기형 | 단어 구성·어종·받침·발음을 교차 검사, 정답 조합형 오답이 매력적이어야 함 |

## 3. 2026 중간고사에서 실제로 확인된 형식
- 선택 1: 본문 작품에 다른 현대시(서정주 「귀촉도」)를 추가 보기로 제시하여 공통적인 정서·표현을 비교하도록 함.
- 선택 3~5와 12~14 등: 작품·해설 관점을 결합한 비교 문항과 서술형 탐구.
- 선택 20~22: 설명형 비문학 지문 속 철학 개념과 인물 관점/새 상황을 교차하여 판단하도록 구성.
- 2026 중간고사는 한글 맞춤법 단원 시험이 아니므로 **가사 사용 빈도의 직접 근거로 삼지 않는다**.

## 4. 과목별(국어 내부) 새 지문 알고리즘
### 문학
1. 학교 본문 작품의 비교축을 먼저 추출(화자, 정서, 소재의 기능, 공간·시간, 시상 전개, 표현법).
2. 외부 시/소설/고전 작품은 그 비교축에서 **공통점 1~2개와 판별 가능한 차이점 2개 이상**을 가진 것을 우선 선정한다.
3. 새 지문을 읽지 않고 원작 암기만으로 풀리는 문항은 REJECT_DECORATIVE_PASSAGE.
4. 실제 2025·2026 기출에 나왔던 특정 추가 보기(예: 「서시」, 「귀촉도」)는 **신선도 낮음**; V3에는 미사용 작품 우선.

### 비문학
1. 처음 보는 개념 X와 Y의 정의, 성립 조건, 관계(대립/포함/인과), 한계/반례를 새 설명 지문에서 *자족적으로* 제공한다.
2. 본문에서 X/Y 대비를 묻고 〈보기〉의 실제 상황에 적용한다. 배경 학술 지식이나 전공 전문용어를 외워야 풀 수 있으면 범위 이탈.
3. 2026 2학기 중간에서 개념과 사례 대응이 실제 확인되지만 **앞으로 등장할 외부 지문의 정확한 주제는 예측할 수 없음**.
4. 추천 설명 주제(새 자작 지문): 디지털 정보의 출처 신뢰도 vs 논리 타당성, 법/윤리에서 규칙과 예외, 문학 텍스트 해석의 근거와 추론. 단 실제 시험범위의 수업 개념과 연계할 것.

### 현대 문법 (한글 맞춤법)
1. 교과서 개념은 고정, 포장은 매번 새롭게: **실제 노래 가사 / 현대시 / 소설 한 장면 / 학생 일기 / 짧은 SNS 글 / 기사 제목 / 교정 대화**.
2. 자료 도입은 실제 문법 조건을 읽어야 하는 수준이어야 한다. 특히 '사이시옷'은 합성어 판정 + 어종 + 뒷말 소리, '띄어쓰기'는 문맥 속 조사/의존명사 구분.
3. **공식 가사 표기=표준 맞춤법의 절대적 증거가 아님**. 리듬·문체에 따른 의도적 비표준 표기, 플랫폼 간 가사 전사 차이를 먼저 검토. 평가 문항은 [원문 표기]와 [규범적 교정안]을 서로 명시하고 정확한 출처·사전 판정을 덧붙인다.
4. 저작권 보호 가사/현대시/현대소설의 장문을 GitHub 원문이나 PDF에 무단 전재하지 않는다. 작품명·링크·판단축만 색인하고, 실제 발췌는 허용 범위·이용허락 확인 후. 대체로 같은 문법 상황을 구현한 **ARC 창작 새 예문**으로 제작할 수 있다.
5. 교과서 밖 규정 제○항의 지엽적 번호를 정답 근거로만 써서는 안 됨. '규정 번호가 익숙한지'가 아니라 '문장 내 원리를 확인할 수 있는지'가 평가 목표.

### 중세 국어
1. 기존 ARC V3가 다른 중세 국어 자료를 쓰는 방향은 유지하되, **원전의 문헌명·권차·간행 시기·원문 행 번호·현대어 풀이를 고정**.
2. 《월인석보》·《석보상절》·《내훈》 등 15세기 언해/문헌은 학교 학습 범위의 표기·문법을 전이 검증할 후보.
3. 《번역노걸대》·《소학언해》 등 16세기 자료는 변화 비교용으로만 사용. 15세기 국어 특징의 직접 증거로 오분류 금지.
4. 이미 출제된 '두시언해' 계열이나 기존 ARC 교재 V3 동일 단락은 신선도 감소. **작품명이 같아도 실제 원문 단락과 사고 축이 같으면 중복**.
5. 의도적으로 문맥을 절단하여 정답이 달라지는 발췌는 BLOCKED_SOURCE.
