## 0. 요청마다 사용자가 정하는 값 (기본값 없음)
다음 값은 이 시스템에 기본값이 없다. 사용자가 이번 요청에서 직접 정한 값만 쓰며, 하나라도 비어 있으면 **생성에 들어가기 전에 사용자에게 묻는다**(추측·이전 요청 값 재사용·아래 참고 예시를 기본값으로 채우는 것 금지).
| 값 | 적용 | 번들 필드 |
|---|---|---|
| 단계 S1~S4 | ARC_N (KOR·SOC·SCI) | request_spec.stage |
| 세트 문항 수 | ARC_N·ARC_FINAL (KOR·SOC·SCI) | request_spec.item_count |
| 난이도 분포(D2·D3·D4+ 비율, D1 은 항상 0) | ARC_N | request_spec.difficulty_targets {D2,D3,D45}, 선택 tolerance(기본 0.12) |
| 기출/창작 구성(PROFILE) | KOR 전 제품 | source_composition.profile |
- 번들에 request_spec.decided_by = USER 를 기록한다. 코드 게이트(production_pipeline)가 request_spec 이 없거나 불완전하면 REQUEST_SPEC_* 로 차단하고, KOR 의 source_composition.profile 이 없으면 SOURCE_PROFILE_UNDECLARED 로 차단한다. 차단 메시지는 "ASK THE USER" 로 시작하며 담당 에이전트는 사용자에게 질문한다.
- 사용자가 정한 난이도 분포는 번들의 실제 분포와 tolerance 안에서 일치해야 한다(REQUEST_DIFFICULTY_*_OFF). 사용자가 분포를 정하면 국어의 기존 고정 혼합 제한(D4+ 15~35% 등)은 적용하지 않는다. D1 금지는 항상 적용된다.
- ARC_FINAL 의 난이도는 사용자 값이 아니라 학교 앵커 + 오프셋(과목별)으로 정해진다. FINAL 도 문항 수는 요청마다 묻는다.
- 아카이브 재실행(--archived-replay)은 이 게이트를 건너뛰지만 최종 출판 가능으로 표시되지 않는다.

## 1. 원칙
- 단계(S1~S4)는 "무엇을 훈련하는가"(사고 동작)로 나눈다. 난이도 D1~D5 는 문항 개별 표시이며 단계와 같은 것이 아니다. N 메타 스트립에는 D2~D5 만 나타난다(D1 금지, §1-A).
- 모든 단계는 같은 범위 잠금(SCOPE_LOCK)을 쓴다. 단계가 올라가도 범위는 넓어지지 않는다(범위 밖 공식·상위학년 기법·범위 밖 철학사 요구 금지).
- ARC_N 은 학교 시험 난도 분포를 맞출 의무가 없다(ARC_FINAL 만 학교 앵커를 따른다). 단, 어떤 단계도 UNIQUE_ANSWER·PASS_A/B·SCOPE_LOCK·전 선지 근거 게이트를 면제받지 않는다.

## 1-A. D1 금지 (사용자 지시 2026-11-08: "D1은 아예 문제에 넣지마", "국어도 d1 지우고")
- KOR·SOC·SCI ARC_N 세트에는 D1 문항을 하나도 넣지 않는다. 모든 단계(S1~S4)에서 허용 난이도는 D2~D5 이다.
- 단순 용어 일치·한 줄 사실 회상 같은 D1 급 문항은 버리거나, 자료 해석·조건 적용이 필요한 D2 이상으로 다시 설계한다. D1 로 표시만 바꿔 채우는 것은 금지한다.
- 세트 안에 D1 로 판정된 문항이 있으면 세트는 불합격이며 해당 문항을 교체한다. 메타 스트립에는 D2~D5 만 나타난다.
- 이 금지는 세 과목의 ARC_N 에 적용한다. ARC_FINAL 은 학교 앵커의 D1·D2 합산 비율을 쓰므로 영향이 없다(D2 로 충족).
- 국어의 기존 D1 허용(10% 이하)은 폐지한다.

## 2. 단계 정의
| 단계 | 사고 동작 | KOR 에서 훈련하는 것 (옛 V번호) | SOC 에서 훈련하는 것 | SCI 에서 훈련하는 것 | D 범위(주력) |
|---|---|---|---|---|---|
| S1 | 개념 확인·식별 | 교과서 시험범위 전체의 기본 개념을 빠짐없이, 다양한 유형으로 (V1) | 개념·용어·사상가 입장의 정확한 정의, 범위 전체를 빠짐없이 | 개념·현상·법칙의 정확한 진술, 범위 전체를 빠짐없이 | D2~D3 (D2 ≥ 50%) |
| S2 | 자료 해석·적용 | 학교자료로 중요도가 뒷받침되는 축에 비중을 두고 복합 판단 (V2) | 지도·표·그래프·사례에서 개념 적용, ㄱㄴㄷ 복수판단 | 표·그래프·모형·실험 결과 해석, 단일 단계 계산 | D2~D4 |
| S3 | 복합 판단·결합 | 둘 이상의 근거·조건을 결합한 문학·비문학·문법 판단, 반례 구분 (V3 의 결합 부분과 V4 일부) | 사상가·제도 비교 + 사례 적용 결합, 반례 구분 | 복수 조건 정량 추론, 자료+개념 결합, 비율·이온 수 등 다단계 | D3~D5 |
| S4 | 새 자료 전이·변별 | 처음 보는 지문·예문·낯선 표현으로 범위 내 개념 전이, 미세 조건 검증 (V3 외부 지문 + V4 + V6 낯선 표현) | 처음 보는 사례·자료로 범위 내 개념 전이, 후보 선지 경쟁 | 처음 보는 실험·자료로 범위 내 개념 전이, 미세 조건 검증 | D3~D5 (D4+ ≥ 40%) |

**참고 예시일 뿐 기본값이 아니다.** 사용자에게 분포를 물을 때 제안으로 보여줄 수 있는 값이며, 사용자가 정하기 전에는 어떤 번들에도 자동 적용하지 않는다. (D1 은 0 이므로 D2 열은 D2 만의 비율)
| 단계 | D2 (D1=0) | D3 | D4·D5 |
|---|---|---|---|
| S1 | 0.65 | 0.30 | 0.05 |
| S2 | 0.30 | 0.45 | 0.25 |
| S3 | 0.15 | 0.40 | 0.45 |
| S4 | 0.10 | 0.35 | 0.55 |
단계 이름과 실제 분포가 어긋나면(예: S4 인데 D4+ 가 0.30 미만) 세트를 해당 단계로 표시할 수 없다.

## 3. 단계별 출제 제약
- S1: 범위의 모든 중단원을 최소 1문항 이상 포함(빠짐없이). 복합 판단·정량 결합 금지(S2 이상). D1 금지이므로 기본 개념 문항도 선지 간 구분 근거가 있어야 하는 D2 수준으로 낸다.
- S2: 자료는 풀이에 필수여야 한다(자료를 지워도 풀리면 불합격). 계산은 한 단계.
- 모든 단계 공통(D-21): 교과서의 개념·예문·표·문장을 그대로 가져와 문항을 만들지 않는다. 교과서는 개념 범위만 정하고, 자료·사례·제시문·수치는 새로 구성해 개념을 전이 적용하게 한다. 선지가 교과서 문장과 사실상 같으면 불합격이며, 정답 근거는 교과서 개념이어야 하되 풀이 경로는 교과서에 나온 사례와 달라야 한다.
- S3: 서로 다른 두 근거 이상을 결합하되 둘 다 범위 안이어야 한다. 단순 장문·계산 노동으로 난도를 올리지 않는다.
- S4: 문항 자료는 현재 세트와 기존 기출에 나오지 않은 새 자료여야 한다. 자료 제목·출처가 정답 단서가 되면 불합격. 정답은 새 자료 안의 정보와 범위 내 개념만으로 결정되어야 한다.

## 4. 기출·변형·창작 구성: 문제은행 재고 기준
사용자 지시(2026-11-08): 문제은행에 문제가 많으면 변형 문제를 요구하고, 적으면 창작 위주로 한다. 단계마다 고정 비율을 두지 않는다.

1. 요청마다 현재 SCOPE_LOCK 안의 CONTENT_VERIFIED 은행 문항 수(B)를 센다. 필요한 기출 기반 문항 수는 ceil(0.7 × 세트 문항 수)(R)이다.
2. B ≥ R 이고 사용자가 변형을 요청하면: ARC_GENERATION_SOURCE_POLICY §1~§9 의 PAST_70_AI_30 을 그대로 적용한다. 기출 기반 문항은 provenance.mode = SELECT_ORIGINAL | PRESERVE_CORE | VERIFIED_VARIANT 이고, 변형은 현재 범위·현재 규칙으로 재검증한다.
3. B < R 이면: source_composition.mode = ORIGINAL_TRIAL 로 창작 위주로 진행한다. authorized_by = "STANDING_USER_RULE_20261108", shortage_reason = "CONTENT_VERIFIED bank B=<n> < R=<n>" 을 기록한다. 기출 비율을 꾸며 채우지 않고, 산출물에 ORIGINAL_TRIAL 임을 밝히며 "70/30 충족"이라고 표시하지 않는다.
4. 재고는 부족하지 않지만 사용자가 창작을 원하면 ORIGINAL_TRIAL 을 쓰되 authorized_by 에 그 요청을 적는다.
5. 재고 수와 선택한 모드는 배치 PRE-FLIGHT 에 기록한다. 재고 수를 확인하지 않고 모드를 정하지 않는다.
6. 이 규칙은 단계와 무관하다. 다만 S4 의 새 자료 조건은 어느 모드에서도 유지한다.

## 4-A. 국어 적용
- 국어의 기출/창작 구성은 고정하지 않는다. 요청마다 사용자가 source_composition.profile(STRUCTURE_REFERENCE_ONLY | PAST_70_AI_30 | 필요 시 ORIGINAL_TRIAL)을 정하며, 정하지 않았으면 묻는다. §4 의 재고 기반 규칙은 SOC·SCI 에만 적용한다.
- 폐지된 V5: ARC_FINAL 과 역할이 겹치므로 FINAL 로 통일했다. 실전 모의고사는 ARC_FINAL 제품이 맡는다(SOC·SCI 와 동일). "V5" 라는 명칭은 더 쓰지 않는다.
- 폐지된 V6: 낯선 표현 문법 모듈은 단계가 아니다. 그 정책 문서(ARC_KOR_V6_*)는 국어 문법 문항의 S3·S4 설계 참고 자료로 남기되, "V6 100문항" 같은 별도 세트·비율 목표(65/100 띄어쓰기 등)는 효력이 없다. 필요하면 S3·S4 문법 세트 안에서 사용자가 새로 정한다.
- 국어 장르별 외부 지문(문학 비교·비문학 새 개념·문법 낯선 문맥)은 S3·S4 에서 쓰며, 원문 고정·저작권·블라인드 규칙은 그대로다.
