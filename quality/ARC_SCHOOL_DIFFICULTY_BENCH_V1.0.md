# ARC_SCHOOL_DIFFICULTY_BENCH_V1.0
VERSION: 1.0
DATE: 2026-09-18
STATUS: ACTIVE
ROLE: 동북고 기출 기반 과목별 난이도 Anchor
TEACHER_STYLE_ANALYSIS: DISABLED

## 0. PURPOSE
과거/현재 동북고 1학년 기출은 출제 교사가 서로 다르므로
문체·선호 유형·단원 비중을 현재 시험에 이식하지 않는다.

기출은 오직 다음을 보정하는 데 사용한다.
- 동북고에서 '쉬움 / 보통 / 변별 / 최상위'가 어느 정도의 사고 부담인지
- 과목별 난이도 폭
- 자료량·추론량·오답 강도와 학교 상대난도의 관계
- 시험 한 세트 안의 난이도 곡선

현재 시험에서 무엇을 출제할지는 CURRENT_SCOPE_DNA가 결정한다.

## 1. DO NOT LEARN FROM HISTORICAL EXAMS
- 특정 교사의 발문 습관
- 특정 단원의 출제 비율
- 특정 문항형 빈도
- 특정 순서의 고난도 배치
- 특정 인물/사례/수치 선호

위 요소를 '올해 출제 예측'으로 사용하지 않는다.

## 2. USE FROM HISTORICAL EXAMS
각 과목별로 다음 4개 난이도 Anchor만 추출한다.

SCHOOL_LOW
- 직접 개념/사실 확인
- 1단계 판단
- 오답이 비교적 쉽게 배제됨

SCHOOL_STANDARD
- 개념 + 자료/사례 1개
- 1~2단계 추론
- 보기 2~3개를 각각 판정
- 학교 평균 수준의 오답 강도

SCHOOL_UPPER
- 여러 조건/진술/자료를 통합
- 2~3단계 이상 추론
- HALF_TRUE 오답 또는 시기·조건 교차
- 실수보다 개념 구분력에서 변별

SCHOOL_EXTREME
- 시험 범위 안에서 여러 개념·조건을 동시에 관리
- 강한 오답과 복합 자료
- 상위권 변별에 적합
- 단, 범위 밖 지식·애매성·노가다는 포함하지 않음

## 3. POINT VALUE POLICY
배점은 약한 보조 신호다.
3.1점이 무조건 쉽고 4.2점이 무조건 어려운 것으로 판정하지 않는다.

우선순위:
1. 실제 해결 구조
2. 추론 단계
3. 자료/조건 부담
4. 오답 강도
5. 계산·읽기 시간
6. 배점

## 4. SUBJECT BENCH — PROVISIONAL

### SCIENCE
난이도 폭: 넓음

SCHOOL_LOW 특징:
- 정의/단위/기본 성질 직접 확인
- 계산이 있어도 1단계

SCHOOL_STANDARD 특징:
- 표·그래프·실험·보기 중 하나를 개념과 연결
- 복수 진술 판정
- 간단한 수치 적용

SCHOOL_UPPER 특징:
- 시간/거리/속도 등 복수 조건 동시 관리
- 실험 결과 + 개념 + 계산 통합
- 입자/그래프/실험도를 해석해 여러 진술 판정

SCHOOL_EXTREME 후보:
- 시각자료가 핵심이며 3단계 이상 추론
- 여러 가능한 조건을 각각 검토해야 함
- 계산 자체보다 조건 설정/모델링에서 난도 발생

ARC 적용:
- D1/D2는 직접 개념 확인
- D3는 자료 1개 + 2단계 추론
- D4는 복수조건/자료통합
- D5는 학교 상위 변별형과 실제 비교 후 제한적으로 부여

### SOCIAL
난이도 기준점: 기본 문항부터 읽기·적용 부담이 비교적 큼

SCHOOL_LOW 특징:
- 핵심 사상/개념 직접 매칭
- 짧은 자료에서 한 개념 식별

SCHOOL_STANDARD 특징:
- 사례를 개념에 적용
- 보기 여러 개 판정
- O/X형 표 또는 간단한 자료 변환

SCHOOL_UPPER 특징:
- 장문 사례/독서자료를 새 상황에 전이
- A/B 사회·사상·관점을 먼저 식별한 뒤 선지 검증
- HALF_TRUE 오답 구분

SCHOOL_EXTREME 후보:
- 여러 관점/사상가의 차이를 한 사례에 동시에 적용
- 낯선 사례 + 강한 오답 + 복수 판단축

ARC 적용:
- 단순 장문이라고 D4로 올리지 않음
- 실제 난도는 '읽기량'보다 개념 전이와 오답 강도로 판단
- 사형 논쟁 등 고난도는 사상가 입장 구별 + 사례 적용 + 조건 추론으로 설계

### HISTORY
난이도 기준점: 사실 밀도와 시기/주체 교차가 핵심

SCHOOL_LOW 특징:
- 단일 인물/사건/제도 직접 확인
- 한 시대의 대표 사실 식별

SCHOOL_STANDARD 특징:
- 지문/사료에서 시기 또는 주체를 찾은 뒤 관련 사실 판정
- 보기 4~5개 중 복수 진술 판별

SCHOOL_UPPER 특징:
- 지도/연표/사료 + 시기 + 국가/인물을 동시에 연결
- 여러 시대의 사실을 교차 비교
- '2개 고르기' 또는 여러 진술에서 정확한 조합 판정

SCHOOL_EXTREME 후보:
- 자료 식별 자체가 1단계이고 이후 선후관계/주체/제도까지 추가 판정
- 오답이 인접 시대 또는 유사 제도를 활용해 강하게 설계됨

ARC 적용:
- 지엽 연도 암기는 고난도로 인정하지 않음
- 사실 개수보다 '교차 관계 수'를 난이도 핵심으로 봄

## 5. CALIBRATION RULE
새 BANK_PASS 문항마다 가능하면 같은 과목 Anchor 2개와 비교한다.

예:
ANCHOR_LOW = 실제 기출 SCHOOL_STANDARD
ANCHOR_HIGH = 실제 기출 SCHOOL_UPPER

새 문항이 둘 사이면 상대 점수로 보정.
교사와 범위가 다르므로 CALIBRATION_DELTA는 원칙적으로 ±8 이내.
현재 시험과 직접 관련된 기출이면 ±15까지 허용.

## 6. CONFIDENCE
과거 다른 교사 기출:
DIFFICULTY_REFERENCE_CONFIDENCE = MEDIUM

현재 시험/직접 관련 기출:
DIFFICULTY_REFERENCE_CONFIDENCE = HIGH

교사 스타일:
CONFIDENCE = DISABLED

## 7. QA LOOP
2시간 QA에서:
1. 새 문제 생성
2. 정확성/품질/시각자료 QA
3. 같은 과목 SCHOOL_DIFFICULTY_BENCH와 비교
4. D1~D5 + SCHOOL_RELATIVE 보정
5. 실제 기출보다 명백히 쉬운/어려운 방향으로 쏠리면 세트 난도만 조절
6. 과거 기출의 문체/구조를 복제하거나 올해 출제 스타일로 추정하지 않음

## 8. FINAL PRINCIPLE
과거 기출은 '무엇이 나올지' 예측하는 자료가 아니라
'동북고에서 어느 정도가 어려운 문제인지' 정의하는 자로 사용한다.
