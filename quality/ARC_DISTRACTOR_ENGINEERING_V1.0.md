# ARC_DISTRACTOR_ENGINEERING_V1.0
VERSION: 1.0
DATE: 2026-09-30
ROLE: 선지 경쟁력(오답 설계) 규칙 — "발문은 쉬워도 선지는 어렵게"
STATUS: ACTIVE
APPLIES_TO: 모든 객관식 (ARC_N / ARC_FINAL / CORE 확인문제), 특히 공통국어2

## 0. 왜 필요한가
난도는 두 경로로 만든다.
- **발문 경로**: 낯선 자료·복수 조건·다단계 추론 (질문 자체가 어렵다)
- **선지 경로**: 질문은 표준 개념·표현이어도 **선지끼리 경쟁**하여 근거를 끝까지 대조해야 한다

핵심 개념 확인용 세트(N°11 등)는 발문을 어렵게 만들 수 없으므로 **선지 경로가 유일한 난도 수단**이다.
2026-09-30 점검에서 N°11·12는 정답이 최장 선지인 비율이 71~72%(무작위 20%)로, 선지를 읽지 않아도 풀리는 문항이 다수였다.
→ 아래 규칙을 세트 납품 전 **게이트**로 적용한다.

## 1. 선지 평준화 (형태 규칙)
1. **길이**: 5개 선지 길이 편차 ±20% 이내. 정답이 최장·최단이 되는 횟수를 세트 기준 각 30% 이하.
2. **구조**: 같은 문형·같은 절 수·같은 어조. (예: 모두 "A는 ~을 통해 ~을 드러낸다")
3. **구체성**: 정답만 구체적(인용어·행 번호·고유명)이지 않게 한다. 모든 선지에 같은 밀도의 지문 근거를 넣는다.
4. **단정어 분산**: 완전히·반드시·직접·확정적·오직·전혀 등은 오답 신호가 되지 않도록 정답·오답에 고르게 쓰거나 아예 쓰지 않는다.
5. **정답 위치**: 번호별 균등, 3연속 금지(기존 규칙 유지). 길이·구체성도 위치처럼 무작위 배분한다.

## 2. 오답 유형 코드 (DT) — 세트 전체에서 다양화
| 코드 | 이름 | 만드는 법 (정답을 어떻게 바꾸나) |
|---|---|---|
| DT1 | 근거 참 · 결론 틀림 | 인용한 지문 근거는 맞으나 그로부터 이끈 해석·효과가 틀림 |
| DT2 | 반쪽 참(HALF_TRUE) | 앞절은 참, 뒷절만 틀림 (또는 반대) |
| DT3 | 대상 바꿔치기 | 화자↔서술자, 갑녀↔을녀, 칸트↔헤겔, (가)↔(나) 특성 교환 |
| DT4 | 위치·시점 바꿔치기 | 연·행 번호, 앞·뒤, 과거·현재, 단계(시작/조정/해결) 교환 |
| DT5 | 범위 확대·축소 | 일부→전체, 가능→확정, 부분 수용→전면 수용 |
| DT6 | 인과·방향 뒤집기 | 원인↔결과, 대비↔유사, 강화↔약화 |
| DT7 | 관찰↔추론 혼합 | 화자가 본 것과 화자가 추측한 것을 섞음 (OBSERVED_FACT vs SPEAKER_INFERENCE) |
| DT8 | 유사 개념 오명명 | 직유↔은유, 귀납↔유비↔연역, 타율↔자율, 구체적↔추상적 자유, 풍자↔해학 |

한 문항에는 서로 다른 DT를 최소 3종 사용한다. 한 세트에서 같은 DT가 30%를 넘지 않게 한다.

## 3. 제작 절차 — 단일 변이 규칙 (Single-Mutation Rule)
1. 정답 선지를 먼저 쓴다 (평서문 1문장, 근거 2개 이내).
2. **오답은 정답을 한 요소만 바꿔서** 만든다 (주어·관계·방향·범위·시점·원인 중 하나). 이렇게 하면 길이·구조가 자동으로 평행하고 정답과 유사도가 높아져 경쟁이 생긴다.
3. 오답마다 DT 코드와 "학생이 왜 고를지"를 한 줄로 기록한다 (오답 설계 기록).
4. 5개 선지를 무작위로 섞는다 (길이 순서도 섞기).
5. `quality/tools/option_cue_lint.py`로 점검하고, 통과 후에 D등급을 붙인다.
6. 부정 발문("적절하지 않은 것"): 참인 진술 4개도 **같은 구체성**으로 쓰고, 거짓 진술은 참인 문장을 한 요소만 바꾼 것으로 만든다. 과잉 단정어로 티 나게 만들지 않는다.
7. ㄱ~ㅁ·개수형: 거짓 진술 중 최소 2개는 HALF_TRUE. "모두/전혀" 같은 표지어로 거짓임이 드러나지 않게 한다.

## 3-1. 기존 문항의 진화 (EVOLVE) — 새 문항보다 우선 검토
중요한 문항(핵심 개념·출제 가능성 높음)은 새로 쓰기 전에 이전 세트 문항을 먼저 진화시킨다. (규칙: ARC_SIMILARITY_GUARD §6)
1. 이전 문항을 린트·CDI로 진단한다 (정답이 최장인가, 0점 오답이 있는가, 단정어 편중인가).
2. 발문은 유지하고 **선지만 단일 변이 규칙으로 재구성** (OPTION_REBUILD) — 쉬운 질문 × 어려운 선지의 기본형.
3. 또는 같은 근거로 **묻는 축을 이동** (ASK_SHIFT): 예) 표현 확인 → 표현 효과 판단, 단일 진술 → ㄱ~ㅁ 진술 판정, 작품 하나 → 두 작품 비교.
4. 개선 전후 지표(최장=정답, CDI, 길이비)를 비교해 좋아졌을 때만 채택하고 계보를 남긴다.
5. 세트 안에서는 같은 근거로 같은 것을 두 번 묻지 않는다.

## 4. 경쟁력 지수 CDI (Competitive Distractor Index)
오답 1개당 0~3점, 문항 CDI = 오답 4개 평균.
| 점수 | 정의 | 판정에 필요한 것 |
|---|---:|---|
| 0 | 지문과 무관하거나 상식으로 배제 | 읽지 않아도 판정 |
| 1 | 용어·개념 정의만 알면 배제 | 개념 암기 |
| 2 | HALF_TRUE — 일부만 틀려 근거 위치 확인 필요 | 지문 대조 |
| 3 | 근거 인용은 정확하나 해석·방향·범위가 틀림 | 대조 + 논리 추론 |

**D등급 상한 (LEVEL CAP)**
| 목표 등급 | 필요 CDI | 추가 조건 |
|---|---|---|
| D2 | ≥ 1.0 | 0점 오답 2개 이하 |
| D3 | ≥ 1.6 | 2점 이상 오답 2개 이상, 0점 오답 없음 |
| D4 | ≥ 2.2 | 2점 이상 오답 3개 이상, 3점 오답 1개 이상 |
| D5 | ≥ 2.5 | 3점 오답 2개 이상 + 발문 경로 난도(복수 자료·낯선 사례) 병행 |
**최종 D = min(구조 점수 등급, CDI 등급, 린트 통과 등급)** — 배점에서 역산한 등급은 금지(순환).

## 5. 린트 게이트 (`quality/tools/option_cue_lint.py`)
기준선: 무작위 20%. 실제 기출(R0: 2025 동북고 n=18)에서 최장=정답 22%(긍정 발문 2/7), 정답/오답 길이비 0.79.
| 지표 | 게이트 |
|---|---|
| 긍정 발문에서 최장 선지=정답 | ≤ 35% |
| 전체 최장 선지=정답 | ≤ 30% |
| 지문 어휘 중복 휴리스틱 정확도 | ≤ 30% (잠정) |
| 정답/오답 평균 길이 비 | 0.75 ~ 1.25 |
| 부정 발문에서 과잉 단정어로 단독 적중 | ≤ 30% |
미통과 세트는 납품하지 않는다. 미통과 문항은 재출제하거나 D2로 강등한다.

## 6. 쉬운 발문 × 어려운 선지 — 변환 예시
### 예 1. 주제 확인 (긍정 발문)
- 전: 정답만 길고 상세하며 오답은 짧고 엉뚱함 → 길이만으로 풀림
- 후 (제목 ‘탄궁가’와 윗글의 주제로 가장 적절한 것은?)
  1. 궁핍한 처지를 탄식하면서도 그 원인을 자신의 분수로 돌리며 현실을 받아들이는 태도 **(정답)**
  2. 궁핍한 처지를 탄식하면서도 그 원인을 세상의 불의로 돌리며 현실에 맞서는 태도 (DT1: 탄식은 참, 귀속 틀림)
  3. 궁핍한 처지를 가난 귀신에게 하소연하면서 끝내 그를 물리치는 데 성공하는 태도 (DT4: 전개 오해)
  4. 궁핍한 처지를 이웃과 나누며 공동체의 도움으로 극복하려는 태도 (DT5: 범위·소재 인접)
  5. 궁핍한 처지를 청빈의 이상으로 미화하여 현실의 고통을 부정하는 태도 (DT8: 수용 vs 부정 혼동)
### 예 2. 부정 발문 (수라)
- 전: "화자의 행위는 흩어진 가족을 다시 만나게 한 구원의 행위이다" — 명백히 과장된 오답
- 후: 참인 진술 네 개를 같은 구체성으로 쓰고, 거짓 진술은 "종이에 받아 옮기는 행위는 대상을 배려하는 태도를 보여 주며, 이 행위로 3연에서 처음으로 가족의 재회가 가능해진다"처럼 앞절은 참·뒷절만 틀린 문장(DT2)으로 만든다.
### 예 3. 표현법 확인 (팔원)
- 전: 직유가 정답, 나머지는 의성어·명령형·대화체 등 시에 없는 요소 (DT 0점)
- 후: 시에 실제로 있는 요소를 오명명/오배치 — "‘밭고랑처럼’은 은유로…(DT8)", "‘~쳤을 것이다’는 목격한 사실을 서술한 것…(DT7)", "‘내지’를 사용해 화자가 일본 문물을 동경함을 드러낸다(DT1)" 등.

## 7. 기록
