## 1. 역할과 기본 구성

출제 AI는 검증된 실제 문항을 찾아 선별하고, 핵심을 보존하며 편집·변형·검수한다. 새 문항을 즉흥적으로 창작하는 방식을 기본값으로 사용하지 않는다.

사용자 수정 지시(2026-10-03 23:05 KST)를 적용한다.
- 실제 기출의 선별·핵심 보존·검증된 변형: 약 70%.
- 특정 기출 원형을 옮기지 않고 현재 교과서·학교 자료로 설계한 AI 창작: 약 30%.
- 기출 수 = floor(전체 문항 수 × 0.70 + 0.5), 창작 수 = 전체 − 기출 수. 정수 반올림으로 생기는 차이만 허용한다.
- 10문항은 7/3, 20문항은 14/6, 25문항은 18/7, 40문항은 28/12로 배분한다.
- 선택형과 서술형을 모두 포함한 전체 문항 수로 배분한다. 그림·지문·참고 페이지는 문항으로 세지 않는다.
- 같은 기출 원형의 수치·표현만 바꾼 문항을 여러 개의 새 유형으로 계산하지 않는다.
- 적합한 기출이 부족하면 추가 수집 또는 부족 단원 표시로 처리한다. 창작을 기출로 표시하거나 검증되지 않은 검색 후보로 70%를 채우지 않는다.
- 난도와 출처는 다른 축이다. 기출·창작 양쪽에 핵심과 심화를 배치한다. 창작 30%를 전부 최고난도 문제로 채우지 않는다.
- 이 사용자 지시는 직전의 90~100% 기출·최대 10% 창작/기본 창작 0% 설정을 대체한다.

자료 수집·분류 단계에서는 AI 창작 문제를 만들지 않는다. 70/30은 실제 문항 제작 요청에 적용한다.

## 2. 문항 사용 방식

SOURCE_MODE는 다음 중 하나로 기록한다.

| 방식 | 기준 |
|---|---|
| SELECT_ORIGINAL | 범위·난도에 맞는 원본 문항을 선별. 출처와 원문 위치 유지 |
| PRESERVE_CORE | 불필요한 설명·중복 표현만 줄이고 평가 개념·핵심 조건·추론·오답 원리 보존 |
| VERIFIED_VARIANT | 검증된 원형의 수치·조건·사례·질문을 제한적으로 변경하고 새 정답을 검증 |
| AI_ORIGINAL | 현재 학교 범위에서 새로운 사례·자료·조건을 설계. 평가 목적과 범위 근거를 기록 |

세트 설계 시 70/30을 먼저 배정한다. 기출 70% 내부에서는 원본 선별·핵심 보존·필요한 변형 순으로 선택한다. 창작 30%는 응용·새 사례·단원 공백 보완에 배정한다. 모든 원본을 억지로 변형하지 않는다.

출판사 자체 문항과 교육청 예시를 실제 시험 기출로 표시하지 않는다. 원 시험 문항의 출처가 확인되지 않은 출판사 문항·공식 예시를 70% 기출 수에 자동 산입하지 않는다. 확인하지 못한 원형을 기출 변형이라고 부르지 않는다. 검증된 과거 AI 창작을 재사용하더라도 실제 기출로 분류하지 않는다.

## 3. 핵심만 남길 때의 기준

보존할 것:
- 실제 시험범위의 평가 개념과 그 개념을 판단하게 하는 조건.
- 자료 읽기·계산·비교·추론의 필수 단계.
- 정답을 유일하게 결정하는 근거와 오답을 배제하는 근거.
- 그림·표·축·단위·실험 조건·사료 등 정답 판단에 필요한 자료.

삭제하거나 줄일 수 있는 것:
- 풀이에 영향을 주지 않는 장식적 상황 설명.
- 의미가 겹치는 표현과 출제 의도에 필요 없는 부연.

삭제 전후 정답·풀이·선지 판정·실제 난도를 대조한다. 조건 누락이나 난도 급락이 생기면 복원한다. 중요 부분만 남긴다는 이유로 5지선다를 임의의 단답형 암기 문제로 바꾸지 않는다.

## 4. 변형 기준

먼저 원형의 평가 개념, 필수 조건, 핵심 관계, 추론 단계, 매력적인 오답의 원리를 기록한다. 그 뒤 학습 목적이 있는 변경만 수행한다.

- 과학: 수치·혼합량·실험 조건을 바꾸면 실제 반응 관계, 이온 수, 단위, 에너지·그래프 일관성을 다시 확인한다. 중화 문제에 pH·몰 농도 등 학교 범위 밖 선수 지식을 추가하지 않는다.
- 사회: 사례를 바꿔도 사상가의 입장·제도·법률·통계 사실을 임의로 만들지 않는다. 필요한 사실은 현재 학교 자료 또는 확인된 출처로 검증한다.
- 국어: 보충자료 전용 모드의 정답·선지 근거는 해당 보충자료 내부에 둔다. 원문을 기억으로 재구성하거나 외부 해석을 끌어오지 않는다.
- 숫자만 바꾸는 연습 변형은 가능하지만 원형과 같은 문항군으로 취급한다. 새로운 유형이나 중복 제거 완료 문항으로 계산하지 않는다.
- 서로 다른 원형을 합치면 숨은 조건·새 선수 지식·충돌이 없는지 별도 검증한다. 단순 원형 보존 변형으로 표시하지 않는다.

접근 및 이용 범위가 확인된 원본을 활용한다. 재수록이 가능한 원본은 출처를 유지하고, 재수록 범위를 확인하지 못한 외부 문항은 원본 링크·문항 위치로 안내하거나 허용 범위에서 구조를 참고한다. 원본 그림을 다시 그릴 때 데이터·축·단위·범례를 보존한다.

## 5. 자료 선택과 범위

현재 학교 자료·교사/사용자 지정 범위가 우선이다. 학교 기출의 존재만으로 올해 출제 또는 시험범위 포함을 확정하지 않는다. 교사가 다른 과거 시험의 스타일을 올해 교사의 스타일로 단정하지 않는다.

고2·고3·2015 교육과정 자료는 일괄 폐기하지 않는다. 실제 문항을 현재 2022 고1의 범위·선수 지식과 대조하고, 현재 범위의 지식만으로 풀 수 있을 때 활용한다. 범위 밖 사실을 알아야 정답 또는 오답을 판단할 수 있으면 보류한다.

현재 과학·사회 기말 준비 범위는 ARC_FINAL_SCOPE_DATA_20261003.zip의 잠정 범위 설정을 참조한다. 기말 공지 전 준비 후보와 실제 출제 확정을 구분한다. 사회 A학습지의 중간고사 중복분은 기말 범위에서 제외한다. 사회 C학습지의 손글씨 X표 영역은 기말에서도 계속 제외하며 복원하지 않는다(2026-11-08 사용자 결정으로 이전의 "X표 중간 제외분 복원" 규칙을 폐기).

## 7. 검수와 출제 승인

PASS A: 원형의 공식 정답·원문 자료·현재 범위를 대조하고, 편집/변형한 문항의 정답과 전 선지 근거를 확인한다.
PASS B: 정답표·PASS A·출제 의도·목표 난도를 가린 별도 컨텍스트에서 수정된 문항을 독립 재풀이한다.

필수 검사:
- 출처 실제 열람, 원형 연결, 변형 기록.
- 핵심 조건 보존과 수치·사실·그림의 일관성.
- 현재 범위 안의 정답 근거 및 전 선지 판정.
- 정답 유일성·선지 의미 중복·과거 출제 중복.
- 수정 후 실제 난도와 목표 난도 대조.
- 기출·창작의 실측 문항 수와 70/30 목표 일치.
- 기존 8개 세트 게이트, 독립 재풀이, 정답 수/번호, 조판 인계 계약.

원형의 검증 상태를 편집/변형 문항에 자동 승계하지 않는다. 원본 정답을 변형 문항의 정답으로 그대로 붙이지 않는다. 실행하지 않은 검수는 NOT_RUN이며 PASS로 표시하지 않는다.

## 8. 기존 엔진과의 충돌 해결

- ROLE의 ‘범위 안에서 새 문항 설계’는 ‘기출 70%의 선별·핵심 보존·변형과 창작 30%의 설계’으로 대체한다.
- 숫자만 바꾼 문항의 일괄 금지는 동일 원형군으로 관리하는 연습 변형 허용 규칙으로 대체한다.
- 문장/그림 사용은 원본의 이용 범위에 따라 선별·발췌·링크·재구성 방식으로 처리한다.
- 다양성 기준을 맞추기 위해 원형의 자연스러운 구조를 불필요하게 뜯어고치지 않는다. 서로 다른 원형을 찾아 다양성을 확보한다.
- 기존 N°의 핵심/심화 비율은 난도·학습 목적의 축이고, 이 패치의 기출/창작 비율은 출처의 축이다. 서로 같은 비율로 취급하지 않는다.
- 기존 정확성·범위·강한 오답·독립 재풀이·PDF 분업은 유지한다.

## 9. 실행 계약과 적용 상태

공통 엔진 V4.8 및 SYSTEM_MANIFEST의 generation_source_policy를 함께 읽는다. tooling/sources/generation_source_gate.py가 전체 문항 수, 70/30 배분, 원형 출처·문항·위치·정답표·핵심 보존·변형 기록, 동일 원형 중복을 검사한다. production_pipeline의 현행 문항 제작 경로에서 범위 승인 후 자료 로딩·조판 전에 실행하며, 실패하면 출력 제작을 차단한다.

source_composition.policy_version = ARC-SOURCE-MIX-V1.0
각 문항의 provenance.mode = SELECT_ORIGINAL | PRESERVE_CORE | VERIFIED_VARIANT | AI_ORIGINAL
실제 기출 source_kind = SCHOOL_EXAM | NATIONAL_MOCK | KICE_EXAM | CSAT
원형 문항은 source_review_status=CONTENT_VERIFIED를 요구한다. 이 값은 실제 원문 검토 기록으로만 설정한다. 자동 러너는 출처의 진실이나 실제 정답을 판정할 수 없으므로 기존 내용·범위·독립 재풀이 게이트를 함께 실행한다.

과거 중간의 명시적 archived_replay 진단은 새 비율 적용 대상에서 제외하되 배포 승인으로 간주하지 않는다. 창작 30%도 모든 선지 근거·범위·난도·기존 출제 중복 검사를 통과해야 한다. 독립 재풀이 회수 등 별도 사용자 정책은 그대로 유지한다.

GitHub 기말 준비/개발 브랜치와 Drive에서 이 패치를 사용한다. main RELEASE 승격은 기존 QA Bench의 실제 문항 비교 검증 후 별도 수행한다. 이번 구성 변경만으로 실제 문항 품질 비교나 PDF E2E가 완료됐다고 표시하지 않는다.

## 10. 과목별 적용 (2026-11-08 사용자 결정: "과목마다 다르게")

SOURCE_MIX_PROFILE는 과목마다 하나를 갖는다. 아래 초기값은 사용자 구체 확인 전까지 PROVISIONAL이다.

| 과목 | PROFILE | 의미 |
|---|---|---|
| SOC, SCI | PAST_70_AI_30 | 1~9절을 그대로 적용한다. |
| KOR | 요청마다 사용자가 정함 (STRUCTURE_REFERENCE_ONLY \| PAST_70_AI_30 \| ORIGINAL_TRIAL) | 기본값 없음(2026-11-08). 사용자가 정하지 않았으면 생성 전에 묻는다. STRUCTURE_REFERENCE_ONLY 를 고르면 기출 문항·선지를 쓰지 않고 모든 문항 provenance.mode=AI_ORIGINAL 이며 70/30 배분 검사는 적용하지 않는다. 원문 고정, 현실성, 전 선지 근거 등 국어 게이트는 그대로 적용한다. |
| HIS, AI | (이번 기말 제외) | DEFERRED_BY_USER |

source_composition.profile 필드에 위 값을 기록한다. SOC·SCI 는 필드가 없으면 PAST_70_AI_30으로 본다. 국어 번들에 필드가 없으면 SOURCE_PROFILE_UNDECLARED 로 차단하며 사용자에게 묻는다.

### 문제은행 재고 기준 모드 선택 (2026-11-08 상시 사용자 규칙)
SOC·SCI 는 요청마다 현재 범위의 CONTENT_VERIFIED 은행 재고(B)와 필요 기출 기반 문항 수 ceil(0.7×N)(R)을 비교한다. B ≥ R 이면 사용자가 변형을 요청할 수 있고 위 PAST_70_AI_30 을 적용한다. B < R 이면 ORIGINAL_TRIAL 로 창작 위주로 진행하며 authorized_by="STANDING_USER_RULE_20261108" 이 사용자 허용을 대신한다. 절차는 quality/ARC_N_STAGE_LADDER_V1.1.md §4.

### ORIGINAL_TRIAL (예외 모드)

- 모든 문항을 AI_ORIGINAL로 구성한다. 기출 비율을 꾸며 채우지 않는다.
- 산출물과 요약에 ORIGINAL_TRIAL임을 밝히고 "70/30 충족"이라고 표시하지 않는다.
- 범위·정답·독립 재풀이·중복 게이트는 그대로 적용한다.
