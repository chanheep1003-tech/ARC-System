## 1. 공통 결론
1. 어려운 문항은 개념이 깊어서가 아니라 **판단 횟수와 자료 가공**에서 어렵다(보기 4개 × 사상가 2~3명, 표 가공 + 변수, 응답표·채점 규칙, 흐름도·벤 도식, 2~3단계 계산).
2. 교과서 문장을 선지로 옮긴 문항은 시험에 나오지 않는다(D-21). 교과서는 개념 범위이고, 사례·발언·수치는 새로 만든다.
3. 오답은 **귀속 오류**(다른 사상가의 입장을 옮김), 정반대 반전, 부분 참, `모든/오직/전혀` 일반화, `A와 달리 B`로 포장한 공통점, 단어 한 개 교체, 제3 입장 혼합으로 만든다.
4. 정답은 지문을 한 걸음 일반화한 진술이고, 정답 번호는 ①~⑤가 고르게 분포한다.
5. 정답률 수치는 확보한 자료에 없다. 난이도 눈금으로 쓸 수 있는 것은 메가 해설의 라벨(상 26%, 중상 16%, 중 36%, 하·중하 22%)과 배점 구간뿐이며, 라벨과 ARC D 등급은 1:1 대응이 아니다.

## 2. 과목별 요점
### 사회(정의관)
- 정의관은 시험당 약 2문항. 롤스-노직 비교가 중심, 공동체주의는 매킨타이어 입장 귀속 판별, 밀은 거의 나오지 않는다.
- 동북고 원안 6번은 원전 인용문 안에서 자유주의/공동체주의 문장의 귀속을 가려내고, 7번은 질문 흐름도(A·B·C)에 들어갈 질문 ㄱ~ㄹ을 고른다(오답 질문에 공리주의가 섞임). 17번은 규칙 + 갑·을·병 응답표 점수 계산이다.
- 서술형은 조건 단어('공동체', '자유')를 지정하고 단어 사용·오개념으로 5/3/1/0점을 매긴다.
### 과학(중화반응)
- 선택형 24 + 서답형 4. 중화반응은 5문항(8~12번) + 서답 1. 보기는 ㄱㄴㄷ 3개 고정.
- 난이도 장치: 표의 최고 온도로 중성 판별, 양이온 모형만 주고 음이온 추론, 이온 ㉠㉡의 정체를 조건으로 확정.
- 오답: 중화점 이후 물 분자 수가 늘어난다는 착각, 극 부호 반전, 구경꾼 이온 혼동.
### 국어(중세국어·맞춤법)
- 중세국어 4~7번, 맞춤법 8~10번. 중세국어 자료에는 현대어 풀이가 붙고, 새 규칙을 시험지 안에서 주고 적용시키는 문항이 있다.
- 부정 발문은 모두 거짓 선지가 하나뿐인 단일 선택이다(N개 고르기 없음).
- 서답형은 문장 틀 빈칸 4개를 각 1점으로 채우고 형식에 1점.
