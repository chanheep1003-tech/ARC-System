## 1. 문항 기록

### [2027학년도 9월 모평(2026.09.02) 언매 35~39]  (매체 40~45는 문법 어미 문항 일부만 기록)
- **35번 | 국어사+어휘/형태 | 색채어**
  - 개념: 색채어의 형성(합성·파생·자음교체·모음교체), 15세기 색채어('-아/어 ㅎ다' 결합형)와 현대 불규칙 활용 연결.
  - 자료 형식: 설명문(약 600자, 예시는 괄호 안 단어: 발갛다/빨갛다, 희붉다, 검디검다, 새빨갛다, 연푸르다). 선지 5개 모두 "단어 쌍/접사"에 대한 일반화 판단.
  - 발문 문형: "윗글을 바탕으로 추론한 내용으로 적절한 것은?"
  - 선지 구조: 각 선지가 (예시 단어) + (설명문 규칙) 대응 판단. 접사 '시-'가 명사에도 쓰이는가(형용사 어근 한정), '연-'의 의미 방향, 자음 경음/격음=더 짙음, 음성모음=더 어두움 규칙의 "비교 대상 단어 짝 존재 여부".
  - 오답 장치: 규칙의 적용 범위(형용사 어근 vs 명사)를 슬쩍 바꿈; '짙붉다'처럼 색채어 아닌 어근('짙다'는 색채어 아님)을 합성 예로 끼움; '파랑'의 짝(퍼렁/빠랑?)이 방향 반대인 점.
  - 킬러 지점: 지문 첫 문단의 "색채어가 아닌 말('짙다, 옅다...')" 정의를 놓치면 선지 ①이 함정.
- **36번 | 중세국어(15c 색채어 형태) + 현대 불규칙 활용 | <학습 활동> 분류**
  - 개념: 15세기 '누르-+-어', '프르-', '검-+-으니' -> 현대 'ㅎ' 불규칙(거멓다 계열) vs 어근 불규칙('푸르다'·'누르다' 러 불규칙) 분류.
  - 자료 형식: <학습 활동> + 분류 그림(트리, 텍스트 추출에서 누락) + [자료] 3줄. 각 줄 = 15세기 문장 조각(약 10자) + 형태소 분석 괄호 + 현대어 풀이 괄호.
  - 발문 문형: "윗글을 바탕으로 <학습 활동>을 수행한…"
  - 선지: ㉠~㉢ 빈칸에 ⓐ~ⓒ의 조합 대응(① ㉠:ⓐ ... ⑤ ㉢:ⓐ,ⓒ) = 번호 조합 선택형.
  - 오답 장치: 형태소 분석이 이미 제공돼 있으므로 헷갈림은 "윗글의 불규칙 활용 정보(ㅎ결합형 vs 비결합형)를 각 ⓐⓑⓒ에 맞게 분류"하는 지점. ⓑ '프르고'는 -아/어 ㅎ다 결합형 아님 -> 현대 '푸르다'(러 불규칙), 지문 3문단의 괄호 문장이 근거.
  - 킬러 지점: 분류 기준 두 개(ㅎ 결합 여부 / 불규칙 종류)가 지문 두 군데에 흩어져 있어 교차 대조 필요.
  - 정답: [미확인] 추정 근거만 기록 (정답 png 미열람).
- **37번 | 의미·화용(대용 표현 '자기') | <보기> + 대화 5개**
  - 개념: 재귀 대명사 '자기'의 선행사가 문맥에서 단일하게 한정되는 경우 vs 중의적인 경우.
  - 자료 형식: <보기>(약 100자) + 짧은 대화 A/B 5쌍(각 40~50자).
  - 발문: "<보기>의 ㉠에 해당하는 예로 적절하지 않은 것은?"
  - 오답 장치: 대화마다 후보 선행사(주절 주어/종속절 주어/발화 상대 언급 인물)가 몇 명인지 세는 문제. '적절하지 않은 것' 부정형.
- **38번 | 음운(국어 규범·음운 변동의 예외) | 교사-학생 대화 + 단어 10개 표**
  - 개념: '한자어 ㄹ 뒤 경음화'(한자어, 2음절, 첫음절 종성 ㄹ 뒤 ㄷ·ㅅ·ㅈ)의 적용/비적용 판별.
  - 자료 형식: 선생님-학생 대화(조건 세 가지 명시, 약 450자) + 단어 10개 목록(한자 병기+표준발음: 결심[결씸], 골격[골격], 발전[발쩐], 별건[별껀], 설득[설뜩], 월권[월꿘], 율격[율껵], 율법[율뻡], 출발[출발], 탈법[탈뻡]).
  - 발문: "[A]에 들어갈 말로 적절한 것은?" (학생 답 = 적용 단어 1 + 비적용 단어 1)
  - 선지: 두 단어 쌍 5개. 
  - 오답 장치: '경음으로 발음되는 모든 단어'를 적용으로 착각하게 함. [별껀][월꿘][율껵][율뻡][탈뻡]은 경음이 나지만 이 규칙의 조건(ㄷ·ㅅ·ㅈ) 밖(ㄱ·ㅂ)이므로 "적용 안 됨(다른 이유의 경음화)". '출발[출발]'은 평음 유지(예외). '결격'을 대화에서 예고하여 학생이 "경음이면 적용"이라는 오개념을 쓰지 못하게 하면서도 선지에는 비슷한 함정을 둠.
  - 킬러 지점: "적용 단어 하나 + 비적용 단어 하나"의 쌍 구조 -> 둘 다 적용 쌍(결심·발전)이나 둘 다 비적용 쌍(율격·출발)을 소거. 직접 추론: 설득(적용)+월권(비적용) 형태가 정답일 가능성 [정답 png 미확인].
- **39번 | 문장 성분·안긴문장 | 예문 ㉠~㉢ 분석** (예문 본문은 이미지 누락)
  - 개념: 보어/필수적 부사어/관형어, 안은문장과 안긴절의 성분.
  - 발문: "㉠~㉢을 분석한 내용으로 적절하지 않은 것은? [3점]" ; 선지 5개 모두 "㉠에는 ~가 있고 ㉡에는 ~가 있다" 비교형.
  - 오답 장치: 필수 성분 vs 수의적 성분 구분, 안긴절 내부 성분(주어/목적어/필수 부사어/관형어) 유무를 세 문장에 걸쳐 교차 비교.
- (매체 40~45) 어미/표현 문항: 43번 '-면서(동시)/-ㄹ 수 있다/-겠-(완곡)/-나요/-었으면' 의 기능 판단 -> 마지막 ⑤ "확신" 오류('-었으면'은 바람). 화법·매체 지문 속 밑줄 어절의 문법 의미를 묻는 형식.

### [2027학년도 6월 모평(2026.06.04) 언매 35~39]
- **35번 | 음운/형태 이론(변이음·이형태·교체) | 설명문 약 700자**
  - 개념: 음운 vs 변이음(상보적 분포), 형태소 vs 이형태, 자동적 교체/비자동적 교체.
  - 자료 형식: 순수 설명문 3문단(예시 [k]/[g], 옷+이/도/만, 빗다 [빋/빈], 굽다 [구버]/[구워]).
  - 발문: "윗글을 이해한 내용으로 적절하지 않은 것은?"
  - 선지: 5개 모두 지문 문장의 재진술; 하나만 반대로 진술('성대 울림이 의미를 구별한다').
  - 오답 장치: 직관(영어는 유성/무성이 변별적)과 국어 규칙(파열음은 비변별적)의 충돌 -> 상식으로 푸는 함정.
- **36번 | 교체 분류 | <자료1><자료2> 표**
  - 개념: ㉠(ㅂ)·㉡(ㄷ)·㉢(ㄱ) 각 음운이 [b/p], [d/t], [g/k]로 실현되는 단어 + 종성 ㅂ·ㄷ·ㄱ을 갖는 용언의 교체형(잡-/잠-, 닫-/단-, 듣-/들-/든-, 춥-/추우-, 먹-/멍-).
  - 자료 형식: 두 칸 표(자료1 단어 2개씩 / 자료2 활용형 3~6개씩), 각 항목에 표준 발음 병기.
  - 발문: "윗글을 바탕으로, ㉠~㉢을 분석한 내용으로 적절한 것은?"
  - 선지: 5개 모두 (무성음 실현 위치) 또는 (교체의 자동/비자동 판정) 진술.
  - 오답 장치: '잠'과 '잡'을 서로 다른 형태소로 보게 하는 함정(이형태), '듣-/들-'(ㄷ 불규칙)과 '춥-/추우-'(ㅂ 불규칙)의 비자동성 vs [단]·[멍]의 자동성(비음동화) 분류.
  - 킬러: 자동적 교체의 정의("반드시 실현되는")가 2개 조건(종성 규칙, ㅁㄴ 앞 규칙)이므로 비음 앞 교체는 자동, 모음 앞 ㅂ -> 우는 비자동.
- **37번 | 문장 성분·시제·겹문장 종합 | 예문 4개 ㉠~㉣ (각 약 35자)**
  - 발문: "㉠~㉣을 분석한 결과로 적절하지 않은 것은? [3점]"
  - 선지: "(문법 범주)를 포함한 문장은 ㉠, ㉡이다" 형 5개 (관형사형 어미 현재 시제 / 관형어 꾸미는 부사어 / 대등 연결어미 겹문장 / 보조용언 진행상 / 필수적 부사어).
  - 오답 장치: 형용사의 관형사형 '-ㄴ'(파랗던=과거 '-던', 붉은=현재)과 동사 관형사형 구별, '아주 새 제품'(부사어가 관형사 수식) 포착, '익어 가고'(진행)와 '가 버렸다'(완료) 구분. 5문장 x 5범주 교차표를 머릿속에 그려야 하는 "분량 킬러".
- **38번 | 중세국어 | <자료> 설명 + 문헌 용례 3개 | 의문문 종결 어미·보조사** (중세국어 정통 출제)
  - 개념: 설명 의문문 -(오/우)뇨 + 체언 뒤 '고', 판정 의문문 -녀 + 체언 뒤 '가', 2인칭 주어 의문문 -ㄴ다.
  - 자료 형식: 설명 약 220자 + ㉠㉡㉢ 용례 각 [중세 국어 어절 3~4개] + [현대 국어 풀이] 쌍. 문헌명은 지시되지 않음(교육용 가공 예문 가능성 높음).
  - 발문: "<자료>의 ㉠~㉢에 대해 탐구한 내용으로 적절하지 않은 것은?"
  - 선지: ㉠(2), ㉡(1), ㉢(2) = 용례마다 1~2개 선지 (어미·보조사의 결합 대상, 의문문 종류, 대답 요구 유형).
  - 오답 장치: ㉢ '-ㄴ다'가 "의문사가 쓰인 설명 의문문" (엇던)인데 선지는 "긍정/부정 대답 요구(판정 의문문)"로 둔갑 -> 의문사 유무로 판별. 지문 설명 마지막 문장("의문문의 종류와 상관없이 동일")과 용례의 의문사를 교차해야 함.
  - 킬러: 현대어 풀이가 힌트('~이냐?')라서 의문사를 보면 풀리는 단순 구조; 난도는 낮은 편이나 '적절하지 않은 것' 부정형.

## 5. 평가원이 중세국어를 묻는 방식 TOP (읽은 범위에서의 관찰)
1. "중세국어 자료 + 지문(개념)에서 규칙을 주고 적용": 규칙(의문문 어미/보조사, 자모의 형식·내용)을 설명한 뒤 용례에 적용하게 함 -> 암기 아니라 읽기·적용. (2026.06 38, 2025.11 36)
2. 짧은 용례 + 형태소 분석 + 현대어 풀이 병기 3줄(㉠㉡㉢): 해독 부담 제거, 판단은 '분류/대응'. (2026.09 36, 2025.09 39, 2026.06 38)

4. 메타 질문: "무엇을 확인해야 의미 변화를 판정하는가"(2025.09 39) -- 조건 구조 추론.

## 6. 내신(고1)에 가져올 수 있는 형식 10줄

9. 단어 형성 직접 구성 요소(IC) 분석: 사전 풀이를 단서로 파생/합성 순서 판정.
