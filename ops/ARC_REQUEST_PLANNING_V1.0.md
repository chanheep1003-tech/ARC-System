# ARC REQUEST PLANNING V1.0
VERSION: 1.0
DATE: 2026-11-11
STATUS: ACTIVE
ROLE: 짧은 제작 요청을 구체적인 제작 계획으로 바꾸는 규칙
DEFAULTS: ops/planning/ARC_PLAN_DEFAULTS_V1.yaml
TOOL: python tooling/arc.py plan

## 0. 원칙
제작 요청을 받으면 문항을 쓰기 전에 계획 카드를 만든다. 계획 없이 문항을 쓰지 않는다.
사용자가 말한 값이 기본값보다 항상 우선한다.

## 1. 계획 카드의 필수 항목
| 항목 | 정하는 방법 |
|---|---|
| 과목·제품 | 요청에서. N제/문제집 = ARC_N, 파이널/모의고사 = ARC_FINAL, 개념서 = ARC_CORE |
| 범위 | 요청에서. 시험 설정의 범위 상태와 막힌 이유를 함께 적는다 |
| 버전 (국어 ARC N°) | 지정값 → 맞춤법·띄어쓰기면 V6 → 같은 범위 기록이 없으면 V1 → 있으면 다음 단계 |
| 총 문항 수 | 지정값 → 기본 국어 50, 사회 20, 과학 20 |
| 단원 세트 | 국어 선택형 11 + 서답형 1, 사회·과학 선택형 18 + 서답형 2 단위로 나눈다 |
| 난도 분포 | 버전 프로필(선택형 기준). 합이 문항 수와 맞아야 한다 |
| 핵심/심화 | 심화 20~30% (게이트와 같은 범위) |
| 문항 원형 배분 | 원형 라이브러리가 있는 영역은 원형별 문항 수를 정한다 |
| 읽을 파일 | manifest 기준 목록 (`arc.py start`가 출력) |

## 2. 묻는 경우와 묻지 않는 경우
- 과목을 알 수 없거나 범위 단서가 하나도 없을 때만 한 번 묻는다.
- 그 밖에는 묻지 않는다. 기본값으로 채운 항목을 "기본값"으로 표시한 계획 카드를 보여 주고 진행한다.
- 사용자가 계획을 고치면 고친 값으로 다시 카드를 만든다.

## 3. 진행 단위
- 단원 세트 1개를 먼저 만든다. 자체 점검과 조판 미리보기를 마친 초안을 사용자에게 보인다.
- 사용자가 방향을 확인한 뒤 나머지 세트를 만든다. 분량이 큰 작업은 세트 사이에서 한 번 확인한다.
- 세트마다 독립 재풀이를 거친 뒤 검증본으로 올린다. 재풀이 전에는 초안이라고 적는다.

## 4. 계획이 거부되는 경우
- 심화 비율이 20~30%를 벗어남
- 국어 ARC N°에 V5를 지정함 (V5는 ARC FINAL)
- 난도 합이 문항 수와 다름
이 경우 문항을 쓰지 않고 계획을 고친다.

## 5. 기록
계획은 `python tooling/arc.py plan … --save runs/<batch>/plan.yaml`로 남기고, 제작이 끝나면 `arc.py log`로 RUN_LOG에 버전·문항 수·난도 분포를 기록한다. 다음 요청의 버전 선택은 이 기록을 본다.
