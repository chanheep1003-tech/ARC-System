# ARC Fact Audit

## 핵심 원칙
**생성과 검증을 같은 패스에서 완료했다고 간주하지 않는다.** 생성자가 맞다고 생각한 전제를 별도 검증 패스가 다시 확인한다.

## 절차
1. 문항에서 검증 가능한 주장을 전부 추출한다.
2. 주장별 근거를 SOURCE_PACKET, 과목 MASTER, 교과서/학습지, 공식자료에서 찾는다.
3. 상태를 부여한다: `CONFIRMED / PARTIAL / NOT_FOUND / CONTRADICTED`.
4. 수치, 단위, 날짜, 고유명사, 정의, 인과, 선후 관계를 별도 체크한다.
5. 정답 선지뿐 아니라 **모든 오답의 틀린 이유가 사실적으로 정확한지** 확인한다.
6. NOT_FOUND/CONTRADICTED가 정답 근거에 있으면 문항을 중단한다.

## 과목별 중점
- 과학: 단위, 조건, 그래프 축, 방향, 실험 통제, 보존/변화 관계
- 사회: 사상가 입장, 개념의 적용 범위, 통계 기준, 법·제도 표현
- 한국사: 연도, 전후관계, 단체·인물, 지역, 정책 주체
- 국어: 작품/지문 근거와 표현 효과, 자료 밖 작가론 남용 금지
- AI: 알고리즘 순서, DFS/BFS, 데이터 처리 단계, 코드 실행 결과

## Hard Fail
- 정답 근거가 출처에서 확인되지 않음
- 오답이 사실은 맞는 문장임
- 자료의 숫자와 선택지 숫자가 불일치
- 출처가 충돌하는데 하나를 임의로 확정
- 역사적 사실/철학자 입장을 현재 범위 밖 해석으로 확장
