# ARC Visual Chem

## 역할
일반 도식 엔진으로 대체하기 어려운 **화학 구조식/분자 그림**을 정확하게 만든다.

## 주 사용 대상
- 통합과학2 화학 파트
- 구조식이 핵심인 개념 정리본
- 화학 결합/분자 구조를 묻는 문항

## 강점
- 전문 구조 데이터 기반이라 임의 그림보다 정확성 높음
- 2D 구조식을 선명하게 출력 가능
- 화학 문항의 'AI 티'를 크게 줄일 수 있음

## 설계 규칙
- 장식보다 구조 정확성 우선
- 원자 기호/결합선/고리 구조 오류 금지
- 교과 범위 밖 전문 표기는 자동 추가 금지
- 학생 수준에 맞는 단순화 허용, 단 사실 왜곡 금지

## 호출 조건
- 구조식이 정답 판단의 핵심일 때
- '분자 구조를 보고 판단' 유형일 때

## 비호출 조건
- 일반 화학 개념도/반응 흐름도만 필요할 때(arc-visual-concept-diagrams 우선)
- 과목이 화학이 아닐 때
