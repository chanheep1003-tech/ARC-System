# ARC Set Editor

## 목적
좋은 문항 여러 개를 단순히 이어 붙이지 않고 **한 회차 문제집/시험지로서 자연스러운 세트**를 만든다.

## 기준
`quality/ARC_SET_EDITORIAL_ENGINE_V1.0.md`와 `ARC_SIMILARITY_GUARD_V1.0.md`를 따른다.

## 편집 축
- 시험범위 커버리지
- 발문/자료 형태 다양성
- 추론 방식 다양성
- 난도 흐름
- 시각자료 간격
- 오답 함정 다양성
- 문장 리듬
- 정답 번호 패턴

## 편집 규칙
- 교과서 목차 순서 그대로 배열하지 않는다.
- 고난도를 마지막에 기계적으로 몰지 않는다.
- 같은 발문·같은 reasoning skeleton이 연속되지 않게 한다.
- 시각자료가 특정 구간에 몰리지 않게 한다.
- 정답 번호를 인위적으로 균등하게 맞추기보다 눈에 띄는 패턴만 제거한다.
- FINAL은 실제 시험 흐름을 우선하고, N°는 학습 효율과 유형 분산을 우선한다.

## Hard Fail
- 동일 골격 3문항 이상 연속
- 같은 시각자료 형태 과밀
- 특정 단원/개념 과대표집
- 세트 수준에서 난도가 사용자 요구와 크게 이탈
