# 미래엔 공통국어2 교사용 교과서 — 기말 범위(3~5단원) 본문 텍스트

- 출처: 미래엔 공통국어2 **교사용** 교과서(Drive `미래엔_공통국어2_교사용교과서.pdf`)를 단원별로 나눈 `공통국어2_교과서_{3,4,5}단원_….pdf`.
- 범위: 중간고사(1회고사) 범위가 1~2단원이므로 기말 범위는 3~5단원이다. (사용자 지정)
- 방법: PDF의 글자 층이 쪽마다 심하게 깨져 있어(중세 국어 글자 등) 쪽 이미지를 보고 옮겨 적었다. 글자 층이 깨끗한 한글 부분은 이미지와 함께 대조했다.
- 저작권: 출판사 저작물이다. 이 저장소는 비공개이며, **공개 저장소로 바꾸거나 외부에 공유하지 않는다.** (저장소 루트 README는 교과서를 Drive에만 두도록 정하고 있으나 사용자가 GitHub 저장을 명시적으로 요청했다.)

## 표기
- `## p.NNN`: 교과서 인쇄 쪽 번호.
- `[교사용 · …]`: 학생용 교과서에는 없고 교사용 교과서에만 있는 내용(지도 방안, 정답, 예시 답, 판서, 수업 차시 표시 등).
- `[그림: …]`, `[QR 코드]`: 그림·사진·QR의 위치만 표시한다. 그림 속 글자는 옮기지 않았다(도표·상자 안의 글자는 옮김).
- `[파란 글씨]`: 본문 옆이나 아래에 파란색으로 달린 풀이.
- `[판독 불확실]`, `(선 읽기 불확실)`: 이미지에서 확정하지 못한 부분.
- 옛한글(중세 국어) 글자와 방점은 이미지를 보고 유니코드 옛한글로 옮겼으므로 자형·방점이 원본과 다를 수 있다. 원본 대조가 필요하다.

## 알려진 한계와 빈 쪽
- **5단원 170~177쪽은 아직 옮기지 못했다.** 178~199쪽만 옮겼다.
  - 5단원 1부(170~185쪽, 7,131,043바이트)는 `download_file_content`로 받으면 응답이 너무 커서 MCP 연결이 끊긴다. 사용자가 1부를 `미래엔_공통국어2_5단원_1부-1_p170-177.pdf`(6,618,102바이트)와 `미래엔_공통국어2_5단원_1부-2_p178-185.pdf`(1,213,878바이트)로 나눠 올렸고, 1부-2는 받았지만 1부-1도 끊겼다. 성공한 가장 큰 파일은 4단원 분할본(6,267,609바이트)이다. 쪽 이미지를 얻지 못해 이미지 기준 옮겨 적기를 할 수 없다.
  - `read_file_content`로 받은 글자 층은 읽을 수 있었으나 단과 상자가 뒤섞이고, 175쪽 본문 지문의 문장부호가 빠지는 등 본문이 온전하지 않아 저장하지 않았다.
  - 이어서 하려면: 1부-1 PDF를 더 작게(예: 170~173쪽, 174~177쪽) 나눠 같은 `교과서` 폴더에 올리면 된다. 그러면 `unit05_소통하고참여하라.md`의 머리말과 `## p.178` 사이에 170~177쪽을 채운다.
  - 178~199쪽은 쪽 옆 지도 방안 글을 확대해 이미지와 다시 대조했고, 글자 층이 읽히는 부분은 글자 층과도 대조했다. 글자 층이 깨진 부분(지도 방안 사이드바 일부)은 이미지만이 근거다.
- 188쪽 ‘사회적 독서와 개인적 독서의 개념과 의의’ 판서 표는 열 머리글과 칸 내용의 대응이 앞의 표와 반대로 인쇄되어 있다. 이미지에 인쇄된 그대로 옮기고 파일에 주석을 달았다.
- 분할본 PDF에 들어 있지 않은 쪽(132~133, 168~169)은 옮기지 않았다. 단원 사이 쪽으로 보이지만 내용은 확인하지 못했다. (사용자 결정: 일단 제외하고 기록)
