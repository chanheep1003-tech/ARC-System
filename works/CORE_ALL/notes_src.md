- C 학습지: 삼권분립은 **개념만**(입법·행정·사법의 분담, 권력 분립의 목적). 견제 수단(법률안 거부권·국정 감사·탄핵·사면·명령 규칙 심사·임명 동의)은 넣지 않음.
