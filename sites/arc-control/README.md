# ARC CONTROL

ARC 브랜드 관리 · 학습 자료 등록 · 문제 편집·검수 · 시험지 출력 시스템.

```
node scripts/build.mjs
node scripts/dev.mjs
node scripts/check.mjs
```

Node 24 이상이 필요합니다. 개발 서버는 출력된 Local URL에서 사용할 수 있습니다. 자료와 승인 기록은 서버 SQLite에 저장하며, 인쇄 화면에서 PDF 저장이나 프린터 출력을 선택합니다.

구현: 원문 해시/위치 저장, 첨부 PDF·이미지 보관, JSON 가져오기·내보내기, 직접 편집, 선지별 근거 검사, 정확한 문항 중복 검사, 수정 충돌 방지, 사용자 검토 승인, 승인 후 잠금, 브랜드 색상, 사이트 점검 기록. AI 생성과 정답을 가린 독립 재풀이는 별도 서버 요청으로 구현되어 있지만 실제 외부 호출은 검증하지 못했습니다.

이전 검증 기록: 실제 SQLite를 사용한 서버 동작 검사와 Chrome 브라우저의 자료 등록→문항 편집→근거 검사→승인→출력 흐름을 통과했습니다. 저장 전 변경 내용을 잃지 않는 검수 동작, 브랜드 색상 저장, 모바일 폭 390px을 확인했습니다. 한 문항 인쇄 샘플은 문제지 1쪽→빈 페이지 1쪽→정답 1쪽이며, 분리 정답지는 1쪽입니다. 장문 지문·100문항·표/도형을 포함한 전체 조판 검증은 아직 하지 않았습니다.

학교 원문 내부에서 출제하고, 검색 참고자료를 시험의 확정 근거로 자동 편입하지 않습니다. 의미 중복·난도·사실 정확성은 별도 사용자 검토를 기록합니다. 최종 승인은 독립 재풀이 통과와 사용자 검토를 모두 요구합니다. 미실행·호출 실패·불일치 문항은 승인되지 않습니다. 재풀이 재시도 시 이전 성공 결과를 먼저 무효화합니다. 기존 승인 기록은 변경하지 않습니다.

GitHub·Google Drive는 채팅에서 접근 확인했습니다. 사이트의 실시간 연결을 활성화하는 도구가 제공되지 않아 사이트 자동 동기화는 미완료입니다. `worker/initial.js`는 확인 시각이 있는 원본 메타데이터 참고 기록이며 실시간 연동이 아닙니다. 계정 토큰은 앱에 복사하지 않습니다.

## 남은 운영 조건

- Sites 소스 Git 호스트 접근이 실행 환경의 네트워크 제한으로 차단되어 사이트를 배포하지 못했습니다.
- Sites 앱 연결 적격성/활성화 도구가 필요합니다. 확인한 공식 ID와 연결 방식만 사용해야 합니다.
- 기존 사이트에 등록된 `OPENAI_API_KEY`는 재등록하지 않습니다. 지원 모델을 확인한 뒤 서버 `ARC_AI_MODEL` 설정과 실제 호출 검증이 필요합니다. 현재 세션에는 Sites 설정·실호출 도구가 없습니다.
- D1 스키마는 `db/schema.ts`에 정의했습니다. 배포 전 drizzle-kit/drizzle-orm 설치 후 `drizzle-kit generate`로 마이그레이션을 생성·검토·저장해야 합니다. `db/local-schema.sql`은 개발용이며 배포 마이그레이션이 아닙니다.
- D1/R2 논리 바인딩 선언을 플랫폼 스키마와 대조한 후, 기존 프로젝트에 정확한 소스 SHA를 저장·배포해야 합니다. 소유자 전용 접근을 유지합니다.
- 현재 생성 프롬프트는 원문 제한을 구현한 초기 경로입니다. manifest가 선택한 모든 ARC 엔진·GOLD 앵커·난도·QA 규칙을 통합한 완성 엔진으로 표시하지 않습니다.

실제 배포, 외부 AI 호출, 방문자 로그인/동의, 실시간 자료 갱신, ARC 전체 회귀 검사는 완료되지 않았습니다. 개발 서버는 루프백 전용이며 공개 노출하지 않습니다. 로컬 DB와 첨부파일은 `.local/`에 저장됩니다.
